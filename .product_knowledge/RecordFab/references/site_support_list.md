# 支持网站列表说明

## 数据权威来源

多维表格（飞书）：[RecordFab-支持网站列表](https://i6a1sqw3p2.feishu.cn/wiki/LRjwwwIHZi7OyCkXCUocTBCAn0c)

知识库不维护网站列表数据本身，所有站点的最新状态以多维表格为准。

---

## 多维表格字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| 站点名称 | 文本 | 网站显示名称，如 YouTube |
| 站点域名 | 文本 | 域名，如 www.youtube.com |
| 状态 | 单选 | 见下方「状态说明」 |
| 成功率 | 数字 | 最后一次上报所在周的录制成功率（%） |
| 统计周期 | 文本 | 成功率对应的统计时间段，如 20260406 - 20260412 |
| 数据来源 | 单选 | ELK（自动采集）/ 手动添加 |
| 统计标识 | 文本 | 客户端上报时使用的内部标识符 |
| 添加时间 | 创建时间 | 记录首次添加到表格的时间 |
| 更新时间 | 更新时间 | 最近一次字段更新时间 |
| 创建人 | 创建人 | - |
| 更新人 | 更新人 | - |

### 状态说明

| 状态值 | 含义 |
|--------|------|
| 展示 | 在客户端支持网站列表中展示，即对外承诺支持录制 |
| 隐藏 | 不在客户端列表中展示 |
| 待确认 | 已采集到录制数据，尚未达到展示阈值或未经人工确认 |

---

## 更新机制

### 自动更新（每日 11:00）
- 数据来源：ELK 自动采集用户驱动的录制上报数据
- 内容：新增站点记录、更新已有站点的成功率和统计周期

### 人工确认（每周一上午）
- 操作人：PM（fab）
- 规则：成功率 ≥ 90% 的站点，由「待确认」改为「展示」
- 结果：状态变更为「展示」的站点，在下次客户端更新后进入展示列表

---

## 客户端展示规则

- 只有状态为**「展示」**的站点出现在客户端支持列表
- 排列方式：以站点名称首字母 A-Z 顺序排列

---

## 知识库使用边界

- 不在知识库中维护具体站点名单，以多维表格为唯一数据来源
- 产品文档、需求文档中如需引用支持站点数量，应注明"以客户端展示列表为准"
- 不对外承诺具体站点名单，因为站点状态会随成功率动态变化
