# RecordFab Open Questions

## P0：现在最该补的

1. ~~RecordFab 的正式产品定位文案是什么？~~ ✅ 已确认（2026-04-17）
   - Tagline："A Powerful Video Stream Recorder - More Than Just Desktop Screen Recorder"
   - 详见 `01_product_brief.md`

2. ~~当前支持的平台只有 Windows，还是还有其他版本？~~ ✅ 已确认（2026-04-17）
   - 仅 Windows：11 / 10 / 8.1 / 8 / 7（32/64 bit），无其他平台版本
   - 详见 `07_technical_constraints.md`

3. ~~免费试用规则是什么？~~ ✅ 已确认（2026-04-16）
   - 3 次免费试用，有效期 1 个月
   - 详见 `06_business_rules.md`

4. ~~收费模式是什么？买断、订阅，还是混合？~~ ✅ 已确认（2026-04-17）
   - 1-Year License $129.99 / Lifetime License $199.99，均为买断制
   - 详见 `06_business_rules.md`

5. ~~登录是否必须？未登录能否录制？~~ ✅ 已确认（2026-04-17）
   - RecordFab 本身不强制登录即可录制
   - 部分流媒体网站需要用户登录后才能播放；用户在集成浏览器内自行登录流媒体账户即可
   - 详见 `06_business_rules.md` 第9节

6. ~~当前是否支持任务列表、历史列表、失败重试？~~ ✅ 已确认（2026-04-16）
   - 支持历史记录和文件列表（My Files）；失败重试待确认
   - 详见 `01_product_brief.md`

## P1：需求写作会卡住的问题

1. ~~录制开始前是否必须完成视频流检测？~~ ✅ 已确认（2026-04-17）
   - 是，检测到可录制视频流是录制的前置条件
   - 详见 `04_interaction_details.md`

2. ~~当前录制速度选项是否全局一致，还是按站点动态变化？~~ ✅ 已确认（2026-04-17）
   - 固定选项（1x / 2x / 3x / 4x / 5x），不按站点动态变化
   - 详见 `04_interaction_details.md`

3. ~~录制中是否允许用户继续浏览其他页面？~~ ✅ 已确认（2026-04-17）
   - 可切换到其他 Tab，但不能在其他 Tab 发起新录制；每次只能录制一个
   - 详见 `04_interaction_details.md`

4. ~~停止录制后是否保留部分文件？~~ ✅ 已确认（2026-04-17）
   - 用户何时点 Stop，文件就生成到那一刻，与视频是否播放完成无关
   - 详见 `04_interaction_details.md`

5. ~~录制完成后有哪些标准动作？~~ ✅ 已确认（2026-04-17）
   - 无操作入口弹出，遮罩消失，页面恢复，My Files 显示气泡
   - 详见 `04_interaction_details.md`

## P2：设计阶段会卡住的问题

1. ~~首页是否存在，还是直接进入集成浏览器？~~ ✅ 已确认（2026-04-17）
   - 有 Home 页作为第一屏，展示热门支持网站和网站内容列表入口
   - 详见 `03_page_structure.md`

2. ~~录制参数区的位置固定在哪里？~~ ✅ 已确认（2026-04-17）
   - 点击 Start 后触发弹窗，不是固定面板
   - 详见 `03_page_structure.md`、`04_interaction_details.md`

3. ~~录制中的状态反馈有哪些核心字段？~~ ✅ 已确认（2026-04-17）
   - 遮罩上只展示已录制时长和 Stop，无速度等其他字段
   - 详见 `03_page_structure.md`

4. ~~当前产品有没有”最近录制”或”录制历史”模块？~~ ✅ 已确认（2026-04-17）
   - My Files 按录制完成时间倒序展示，无单独的”最近录制”快捷入口
   - 详见 `03_page_structure.md`

5. ~~是否有站点能力提示组件？~~ ✅ 已确认（2026-04-17）
   - 没有

## P3：技术与平台差异

1. ~~是否支持后台录制？~~ ✅ 已确认（2026-04-17）
   - 支持，最小化到后台录制可继续进行

2. ~~是否支持多任务并发？~~ ✅ 已确认（2026-04-17）
   - 不支持，每次只能录制一个任务

3. ~~是否支持计划录制？~~ ✅ 已确认（2026-04-17）
   - 当前不支持；有用户反馈，已列入需求池，尚未上线

4. ~~不同站点的限制如何表达？~~ ✅ 已确认（2026-04-17）
   - 不做任何提示，部分站点仅支持 1x 时静默按 1x 执行

5. ~~输出目录、文件命名、空间检查规则是什么？~~ ✅ 部分确认（2026-04-17）
   - 默认目录：`%AppData%\DVDFab\RecordFab\`，用户可在设置中修改
   - 磁盘空间不足时有提示
   - 文件命名从页面 HTML `<title>` 自动取得
