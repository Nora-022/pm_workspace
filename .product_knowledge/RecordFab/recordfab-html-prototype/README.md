# RecordFab HTML Prototype

这是一个面向桌面客户端形态的静态 HTML 原型，用来把当前依赖 Axure 的产品结构迁移为可继续演进的前端骨架。

## 已包含内容

- 客户端壳结构：左侧导航 + 顶部状态栏 + 主工作区
- 核心页面：首页、录制工作区、定时任务、我的文件、设置
- 与 RecordFab 文档一致的核心心智：浏览器录制、流检测、录制状态、定时任务、文件管理、云盘上传
- 轻量交互：tab 切换、任务详情切换

## 文件

- `index.html`：页面结构
- `styles.css`：视觉样式
- `script.js`：页面切换和任务详情交互

## 使用方式

直接用浏览器打开 `index.html` 即可查看原型。

## 下一步建议

1. 把蓝湖设计稿中的颜色、字号、间距、图标和真实组件替换进来。
2. 把你的客户端截图切成参考资源，逐页对齐 Home / Browser / Files / Settings。
3. 如果后面要给 AI 解读或继续开发，建议下一步改成组件化目录，例如 `pages/`、`components/`、`tokens/`。
