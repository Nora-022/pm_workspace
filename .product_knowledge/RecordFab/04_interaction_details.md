# 04 交互细节（Interaction Details）

## 开始录制
- 触发方式：用户在集成浏览器内进入目标视频页面后，点击 `Start`。
- 前置条件：
  - 已检测到可录制视频流
- 流程：
  1. 系统检测可录制视频流
  2. 用户设置输出分辨率、录制速度和自定义录制时间
  3. 用户确认后开始录制

## 录制前配置弹窗
- 当前共有 3 个参数：
  - 输出分辨率
    - 可选项：`1080` / `720`
    - 含义：输出分辨率，不代表源视频的实际分辨率
    - 当前规则：允许低转高，但清晰度不会真的变高
  - 录制速度
    - 可选项：`1` / `2` / `3` / `4` / `5`
    - 含义：对应 `1x` / `2x` / `3x` / `4x` / `5x` 倍速录制
  - 自定义录制时间
    - 默认关闭
    - 开启后显示时间输入框
    - 输入单位为分钟
    - 默认值为 `2`
    - 到时后自动结束录制

## 录制中
- 录制时视频播放界面有遮罩层。
- 用户无法直接操作视频内容。
- 遮罩上展示：
  - 已录制时长
  - `Stop`
- 不支持暂停。
- 不支持继续。
- 用户只能点击 `Stop`，或强制关闭产品。

## 停止录制
- 点击 `Stop` 后：
  - 结束当前录制
  - 录制遮罩消失
  - 视频播放页恢复正常
  - `My Files` Tab 显示数字气泡 `1`
- 默认不自动跳转到 `My Files`
- 输出文件以停止时刻为准：用户何时点 Stop，文件就生成到那一刻，与视频是否播放完成无关。

## 自动结束录制
- 当用户开启“自定义录制时间”后，到达设定时间会自动结束录制。
- 自动结束后的页面结果与手动点击 `Stop` 一致：
  - 遮罩消失
  - 当前页恢复正常
  - `My Files` 显示新增文件气泡

## 查看结果
- 用户点击 `My Files` 后查看新增文件。
- 新增文件显示为视频卡片。
- 卡片展示：
  - 时长
  - 文件大小
  - 输出分辨率
  - 打开文件夹 icon
- 点击打开文件夹 icon 会打开本地目录。

## 文件命名与磁盘空间
- 文件命名从页面 HTML `<title>` 自动取得。
- 默认输出目录：AppData 下 DVDFab 文件夹内的 RecordFab 子文件夹。
- 用户可在设置中修改输出目录。
- 磁盘空间不足时有提示。

## 设置：Video Bitrate

背景：因输出视频文件过大问题，在 Setting 页新增码率配置项。

标题：**Video Bitrate**

包含两个下拉框：

**1080P Bitrate**
| 选项 | 档位名称 |
|---|---|
| 2500 Kbps | Lite |
| 4000 Kbps | Basic |
| 5500 Kbps | Standard |
| 7000 Kbps | Enhanced |
| 8500 Kbps | Premium |
| 10000 Kbps | Ultra |

**720P Bitrate**
| 选项 | 档位名称 |
|---|---|
| 1500 Kbps | Lite |
| 2500 Kbps | Basic |
| 3500 Kbps | Standard |
| 4000 Kbps | Enhanced |
| 4500 Kbps | Premium |
| 5000 Kbps | Ultra |

备注文案：
> Note: Set the bitrate to fit your network and quality needs. Lower bitrates may impact quality, while higher ones can increase file size.

## 站点速度限制
- 部分站点仅支持 1x 录制速度，产品不做任何提示，直接按 1x 执行。
- 速度选项 UI 不会因站点差异而动态变化。

## 失败处理
- 录制失败后不支持一键重试。
- 用户需重新播放视频并重新发起录制。

## 并发与 Tab 切换规则
- 每次只能进行一个录制任务，不支持并发录制。
- 录制中可以在集成浏览器内切换到其他 Tab，但切换后无法发起新录制。
- 录制遮罩仅覆盖当前录制页，不影响其他 Tab 的浏览。
- 最小化到后台时录制可继续进行。
