## 调研过程

### PlayOn Cloud 产品分析

**PlayOn Cloud 是什么**
PlayOn Cloud 是一款面向流媒体的云端 DVR 产品。用户在 App 中发起录制指令，云端自动完成录制，用户随时下载或在线回放，无需自己的设备在线。

**核心实现机制**

PlayOn Cloud 本质是一套「云端代理录制」方案，分四层：

```
用户 App 发起录制指令
    ↓
PlayOn 云端启动一台虚拟机（Virtual Machine）
    ↓
虚拟机打开浏览器，用用户的流媒体账号登录，实时播放视频
    ↓
对浏览器画面做屏幕录制（Screen Capture），输出为 H.264/MP4
    ↓
文件上传至 PlayOn 云存储，用户下载或在线播放
```

关键点：**不破解 DRM，而是绕过 DRM**。云端虚拟机正常解码播放视频，录制的是解码后的屏幕画面，因此不涉及直接破解加密，法律上属于"屏幕录制"范畴。代价是视频经过一次重编码，有画质损失。

**用户账号与凭证处理**

用户需要将自己的流媒体账号（Netflix、Hulu 等）的密码提供给 PlayOn。存储策略：
- 密码**加密存储在用户本地设备**，不持久存放在 PlayOn 服务器
- 仅在触发录制时，通过加密通道临时发送至云端虚拟机完成登录
- 录制完成后，虚拟机销毁，凭证不留存

**录制时序**

- 录制时长 = 视频时长（1:1 实时，无法加速）
- 录制完成后自动上传云端
- 用户再下载到本地，需额外等待下载时间
- 总等待 = 录制时间 + 下载时间

**存储与分发**

- 录制文件云端默认保存 **7 天**，到期自动删除
- 付费可升级为永久存储
- 支持：App 内在线播放、下载到手机/PC、投屏到电视（Roku/Chromecast/Fire TV）

**定价与商业模式**

Credits 积分制：
- 基础套餐约 $4.99/月，含 30 个录制点数 + 100GB 云存储
- SD/HD 消耗 1 点，Full HD（1080p）消耗 3 点
- 单点约 $0.20–$0.30

**支持平台**
Netflix、Disney+、Hulu、Prime Video、Max、Peacock、Paramount+ 等主流欧美流媒体，**暂不涵盖日本本土平台**。

**主要局限**

| 维度 | 问题 |
|------|------|
| 画质 | 二次编码导致压缩损失，暗场景尤为明显 |
| 速度 | 1:1 实时录制，不能提前录好再看 |
| 音频/字幕 | 仅单音轨，字幕硬编码 |
| 适用场景 | 适合轻量临时录制，不适合构建永久媒体库 |
