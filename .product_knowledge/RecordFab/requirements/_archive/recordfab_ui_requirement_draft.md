# RecordFab UI 需求草稿

## 文档状态
- 版本：v0.1
- 状态：草稿

## 1. 文档目标
- 定义 RecordFab 首版关键界面和录制流程的 UI 设计输入。

## 2. 当前已确认的设计约束
1. 产品是流媒体录制工具，不是通用录屏工具。
2. 集成浏览器是核心工作区。
3. 录制状态必须强反馈。
4. 站点和速度限制必须在开始前尽量说明。

## 3. 重点页面
1. 首页 / 最近任务页
2. 集成浏览器工作区
3. 录制控制区
4. 录制中状态页
5. 录制结果页
6. 设置页

## 4. 重点设计任务

### 4.1 浏览器工作区
- 目标：
  - 用户能在内容页附近直接完成录制参数设置和开始录制
- 需要设计：
  - 参数区位置
  - 检测成功状态
  - 限制提示样式

### 4.2 录制中状态页
- 目标：
  - 用户明确知道录制正在正常执行
- 需要设计：
  - 进度或时长反馈
  - 停止按钮
  - 异常提示位置

### 4.3 录制结果页
- 目标：
  - 强调“已保存到本地”
- 需要设计：
  - 文件结果摘要
  - 打开目录
  - 再录一个

## 5. 待确认后再细化的内容
1. 是否有历史列表
2. 是否有任务队列
3. 是否有订阅 / 权益展示页
4. 首页是否固定存在
