# UI Patterns

## Pattern 1: 浏览器工作区 + 录制控制区
- 适用场景：用户已经进入目标内容页
- 正确结构：
  - 主区域展示站点内容
  - 侧边或底部展示录制参数和状态
  - 主按钮始终清晰可见
- 避免：
  - 把参数散落在多级设置页
  - 让用户为了开始录制频繁跳页

## Pattern 2: 录制中状态页
- 适用场景：录制任务已开始
- 正确结构：
  - 显示进行中状态
  - 显示时长或进度
  - 提供停止入口
- 避免：
  - 只显示 loading
  - 没有停止入口

## Pattern 3: 结果确认页
- 适用场景：录制完成
- 正确结构：
  - 明确提示已保存
  - 提供打开目录
  - 提供继续录制入口
