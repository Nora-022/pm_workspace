# StreamFab TVer Downloader for Browser

面向日本 TVer 平台用户的单站点浏览器下载插件。

| 维度 | 取值 |
| --- | --- |
| 检测模式 | **netflix_mode** |
| 上线状态 | 待研发 |
| 站点 | `tver.jp` |
| 地区 | 日本（AVOD 免费追剧平台） |
| 内容形态 | 日本电视台联合点播（日剧 / 综艺 / 纪录片 / 动画） |
| 跳转 slug | `tver-downloader` |
