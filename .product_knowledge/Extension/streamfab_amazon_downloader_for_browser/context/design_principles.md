# Amazon 设计原则摘要

## 设计优先级
1. 单站点识别清晰
- 产品应被理解为 Prime Video 插件，而不是泛 Amazon 媒体工具。

2. 权益状态透明
- UI 应尽量在创建任务前区分 Prime-included、rental / purchase、不支持等状态。

3. 层级结构保留
- 如果页面暴露 `season -> episode` 结构，下载弹窗应尽量保留，而不是直接打平。

4. 营销表达克制
- Banner 和商店素材只使用产品页和商店页已确认的能力。
- 不要暗示 4K、HDR、全量 live / sports 支持。

5. 截图选择
- 优先使用标题详情页和剧集详情页截图，而不是只放首页截图。
