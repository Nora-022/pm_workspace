# Amazon 来源盘点

## 用途
- 用来快速判断一条结论到底来自哪里
- 方便后续复用时先看可信度

## A. 高可信产品来源
- `https://streamfab.dvdfab.cn/amazon-downloader.htm`
  - 适合确认：
    - 能力文案
    - 分辨率
    - 音频
    - 输出格式
    - 编码
    - 字幕处理
    - metadata 保存
    - 定时下载
    - 价格线索
    - 范围文案

## B. 公开站点结构来源
- `https://www.primevideo.com/`
  - 适合确认：
    - 顶部导航
    - 登录入口
    - Prime join
    - channels / sports / live 的可发现性

## C. 公开详情页结构来源
- 公开电影详情页
  - 适合确认：
    - CTA 类型
    - audio-language / subtitle 标签
    - cast / studio / advisory 元数据
- 公开剧集详情页
  - 适合确认：
    - season switcher
    - episode list
    - 单集 CTA 模式

## D. Help / 支持来源
- `https://www.primevideo.com/help`
  - 适合确认：
    - 官方概念名称
    - downloads
    - rent / buy
    - subtitles
    - audio-description / alternative-audio

## E. 商店详情页来源
- Chrome Web Store 详情页
  - 适合确认：
    - 当前公开发布状态
    - 扩展 ID
    - 标题
    - 版本
    - 发布方
    - 对外功能描述
    - 隐私与本地处理文案

## F. 可信度提醒
- 产品页适合用于理解能力宣传与市场口径
- 公开站点结构适合用于记页面类型与内容类型
- 商店文案适合用于理解当前公开承诺给用户的能力
- 这些都不能替代真实插件运行行为验证
