# StreamFab Amazon Downloader for Browser

面向 Amazon Prime Video 用户的专用浏览器下载插件，仅支持 `primevideo.com` 单站点。

| 维度 | 取值 |
| --- | --- |
| 检测模式 | **netflix_mode**（标准） |
| 上线状态 | 已上线（Chrome 已发布 / Edge 审核中） |
| 视频画质 | 最高 1080p（Widevine L3 浏览器限制） |
| Banner 文案锚点 | 1080p、MP4 / MKV、AAC 2.0 / EAC3 5.1 |
| 产品页 | https://streamfab.dvdfab.cn/amazon-downloader.htm |
