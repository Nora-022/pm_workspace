# 00 概览

## 产品定位
- 产品名称：StreamFab Amazon Downloader for Browser
- 产品类型：独立单站点浏览器插件
- 支持范围：Prime Video

## 已确认事实
- 客户端产品页：`https://streamfab.dvdfab.cn/amazon-downloader.htm`
- 目标站点：`https://www.primevideo.com/`
- Chrome 商店页已发布并审核通过，扩展 ID 为 `hklfhiaihmmnodbbckgcleegglapjlfk`，版本为 `1.0.0.1`
- 产品页已明确提及：`1080p`、`EAC3 5.1 / AAC 2.0`、`MP4 / MKV`、`H.264 / H.265`
- 产品页已明确提及：字幕合并 / SRT 导出、定时下载新剧集、metadata 保存、rental / purchased movies 相关能力
- Prime Video 页面存在 Movies、TV shows、Sports、Live TV、Channels 等内容形态
