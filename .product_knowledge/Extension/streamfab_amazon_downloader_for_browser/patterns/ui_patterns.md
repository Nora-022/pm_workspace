# Amazon UI 模式

## 模式 1：Detected 标题卡片
- 用途：
  - 展示从当前 Prime Video 页面识别出的可处理标题。
- 关键元素：
  - checkbox
  - 海报 / 缩略图
  - 标题与元数据
  - 权益提示
  - 进入下载配置的入口
- 重点：
  - 标题身份与权益状态要同时可见。
  - 不要隐藏该标题到底是 Prime-included 还是 rent / buy。

## 模式 2：剧集选择树
- 用途：
  - 页面暴露 `season -> episode` 时展示层级结构。
- 关键元素：
  - 分季切换或分组树
  - 单集列表
  - 单项选择状态
  - 批量选择入口
- 重点：
  - 尽量保留层级。
  - 这类层级承载了实际内容意义，不宜随意打平。

## 模式 3：权益状态提示块
- 用途：
  - 解释为什么当前标题不能下载。
- 常见状态：
  - 需要登录
  - 需要 Prime
  - 需要 rental / purchase
  - 需要 channel entitlement
  - sports / live 当前不支持
- 重点：
  - 先解释原因。
  - 如果存在明确下一步，再给出下一步。

## 模式 4：下载配置面板
- 用途：
  - 创建任务前配置下载参数。
- 预期配置区：
  - 视频画质
  - codec
  - 音频语言
  - 字幕语言 / 字幕处理方式
- 重点：
  - 只展示插件真实支持的控件。
  - 可以记住产品页有这些能力，但不能凭空补出控件。

## 模式 5：不支持内容状态卡
- 用途：
  - sports / live 或其它非标准页面类型。
- 重点：
  - 显式提示不支持。
  - 不要制造假阳性的 detected 状态。
