# Amazon 错误处理模式

## 模式 1：权益阻断
- 场景：
  - 未登录
  - 没有 Prime 权益
  - 需要 rental / purchase
  - 需要 channel 权益
- 规则：
  - 应明确提示当前权益状态
  - 不要把所有失败都写成统一的 `not supported`

## 模式 2：地区或可用性阻断
- 场景：
  - 当前地区不可播放
  - 当前账号或市场限制导致不可用
- 规则：
  - 如果已有证据，应直接提示地区 / 可用性问题
  - 不要在没有用户动作意义的情况下只给 `Retry`

## 模式 3：live / sports 不支持
- 场景：
  - 当前页面属于 `Sports` / `Live TV`
- 规则：
  - 应在创建任务前明确提示暂不支持

## 模式 4：环境失败
- 场景：
  - CoApp 不可用
  - 磁盘问题
  - 任务移交失败
- 规则：
  - 应体现为任务级失败
  - 权益问题和环境问题要分开记录
