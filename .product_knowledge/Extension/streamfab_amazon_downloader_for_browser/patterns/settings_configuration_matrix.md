# Amazon 配置矩阵

## 产品页已支持的能力线索

| 配置项 | 公开证据 | 可信度 |
|---|---|---|
| 视频分辨率 | 产品页提到 `480p / 720p / 1080p` | 高 |
| 视频编码 | 产品页提到 `H.264 / H.265` | 高 |
| 音频选择 | 产品页提到预选音频语言 | 中 |
| 字幕选择 | 产品页提到预选字幕语言 | 中 |
| 字幕输出 | 产品页提到合并或导出 SRT | 高 |
| metadata 保存 | 产品页提到 title / cast / season / cover | 高 |
