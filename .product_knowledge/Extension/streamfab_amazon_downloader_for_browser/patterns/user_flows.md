# Amazon 用户流程

## 流程 1：Prime-included 电影下载
1. 用户打开 Prime Video 电影详情页
2. 插件识别标题元数据与权益 CTA
3. 用户打开下载弹窗
4. 用户确认可用的画质 / codec / 语言选项
5. 任务创建并进入队列

## 流程 2：剧集批量处理
1. 用户打开剧集详情页
2. 插件构建 `season -> episode` 结构
3. 用户选择一个或多个剧集，或整季
4. 用户确认公共下载配置
5. 任务批量创建并进入队列

## 流程 3：rental / purchase 阻断标题
1. 插件识别到页面出现 `Rent`、`Buy` 或 `More purchase options`
2. 插件判断当前是否存在有效播放权益
3. 若无权益，应明确提示当前受限，而不是假装可下载
4. 如果后续验证确实支持，再补成正式能力

## 流程 4：live / sports 不支持页面
1. 用户打开 `Sports` 或 `Live TV` 页面
2. 插件识别这是非标准 VOD 内容
3. 插件提示当前不支持
4. 不应允许用户创建明显异常的任务
