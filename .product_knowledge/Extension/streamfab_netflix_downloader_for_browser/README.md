# StreamFab Netflix Downloader for Browser

面向 Netflix 用户的专用浏览器下载插件，仅支持 `netflix.com` 单站点。

| 维度 | 取值 |
| --- | --- |
| 检测模式 | **netflix_mode**（基线活样例） |
| 上线状态 | 已上线 |
| 视频画质 | 最高 1080P + HDR + Dolby Vision |
| Banner 文案锚点 | 1080P with HDR and Dolby Vision、Atmos / EAC3 5.1 |
| 产品页 | https://streamfab.dvdfab.cn/netflix-downloader.htm |
