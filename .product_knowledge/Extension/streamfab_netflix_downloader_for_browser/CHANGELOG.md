# Netflix Downloader for Browser Changelog

本文档记录 Netflix Downloader for Browser 的版本更新历史，按版本倒序整理。

## 版本历史

### Netflix 1005 + CoApp 1003 | 已发布

- 新增：支持下载与分析任务并行处理。用户可在下载任务进行的同时分析新视频，大幅提升整体效率，节省等待时间。
- 修复：修复若干已知问题，进一步提升产品稳定性。

### Netflix 1004 | 已发布

- 修复：订阅链接跳转路径问题。
- 修复：部分界面布局细节。
- 修复：其它已知问题，提升运行稳定性。

### Netflix 1003 + CoApp 1002 | 已发布

- 修复：部分源检测不出视频的问题。
- 修复：部分已知问题。

### Netflix 1002 + CoApp 1001 | 已发布

- 新增：支持 Chrome 与 Edge，全面适配主流 Chromium 内核环境，更多信息：https://streamfab.dvdfab.cn/streamfab-for-browser.htm
- 新增：支持 Netflix 站点的剧集/电影下载。
- 新增：支持加速下载，显著提升视频获取效率。
- 新增：支持剧集下载，自动识别剧集列表并连续下载。
- 新增：支持字幕选择与下载，可识别多语言字幕轨道并自由选择。
- 新增：支持最高 1080p 视频分辨率输出，获得更清晰的画面质量。
- 新增：支持 H.264/H.265 视频编码选择，获得最佳播放器兼容性与更佳压缩效果。
- 新增：支持保留 HDR10/Dolby Vision 视频画质，在离线文件中保留高级动态范围体验。
- 新增：支持保留 EAC3 5.1/Dolby Atmos 清晰音频，确保离线播放拥有宽广清晰的音效。
- 新增：支持 MP4、MKV 格式输出，兼容更多设备与播放器。
- 新增：支持 28 种语言的界面与内容识别，方便不同语言环境使用。
