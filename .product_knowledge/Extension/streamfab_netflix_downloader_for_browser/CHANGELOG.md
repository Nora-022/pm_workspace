# Netflix Downloader for Browser Changelog

本文档记录 Netflix Downloader for Browser 的版本更新历史，按时间倒序整理。

## 版本历史

### 2026-04-14 | 计划发布 | Netflix 1005 + CoApp 1003
- 新增：支持下载任务与视频分析任务并行执行。下载进行时，仍可继续分析新视频，整体效率进一步提升。

### 2026-03-06 | 已发布 | 1.0.0.9
- 优化：改进下载引擎，提升稳定性与性能。
- 修复：修复从 YouTube 下载视频失败的问题。
- 修复：修复部分用户授权失败的问题。
- 修复：优化检测列表任务过多导致的卡顿问题。

### 2026-01-26 | 已发布 | 1.0.0.8
- 修复：修复播放列表结果下载顺序异常的问题。
- 修复：修复重复下载同一视频导致失败的问题。
- 修复：修复其他已知问题，提升整体稳定性。
- 兼容性说明：插件与 CoApp 需保持为最新版本，以确保最新功能可正常使用。

### 2026-01-12 | 已发布 | 1.0.0.7
- 修复：修复 Fab 365 用户无法授权的问题。
- 修复：修复部分界面兼容性问题，提升稳定性与显示效果。
- 修复：修复若干已知问题，提升产品稳定性。
- 兼容性说明：插件与 CoApp 需保持为最新版本，以确保最新功能可正常使用。

### 2025-12-26 | 已发布 | 1.0.0.6
- 新增：支持自定义视频输出目录，可分别配置日志、临时文件和下载路径。
- 修复：优化授权流程，改进授权结果提示和操作引导，使授权反馈更加清晰。
- 修复：优化 Detected 页默认勾选逻辑，已发起下载的视频不再默认选中，并支持按需手动选择不同质量版本下载。
- 修复：修复 Fab365 用户无法正常享受插件付费权益的问题。
- 修复：修复部分界面适配问题，提升稳定性与显示效果。
- 修复：修复若干已知问题，提升产品运行稳定性。
- 兼容性说明：插件与 CoApp 需保持为最新版本，以确保最新功能可正常使用。

### 2025-12-16 | 已发布 | 1.0.0.5
- 新增：支持 Google 账号一键快捷登录，提升易用性。
- 新增：引入按站点聚合的任务管理机制，对同站点任务进行集中展示和批量处理，提升多任务场景效率。
- 新增：优化视频解析与加载速度，加快单视频卡片展示，显著提升剧集解析性能，并明显缩短整体等待时间。
- 修复：调整部分界面布局，提升交互一致性与可用性。
- 修复：修复若干已知问题，进一步提升稳定性与使用体验。

### 2025-12-02 | 已发布 | 1.0.0.4
- 修复：修复若干已知问题，提升产品稳定性与使用体验。

### 2025-11-23 | 已发布 | 1.0.0.3
- 优化：优化部分页面布局细节，提升整体美观度与使用体验。
- 修复：修复若干已知问题，使产品运行更加稳定流畅。

### 2025-11-21 | 已发布 | 1.0.0.2
- 新增：支持 Chrome 和 Edge，并全面兼容主流 Chromium 内核环境。
- 新增：支持下载来自 1000+ 视频站点的视频和音频，包括 Dailymotion、Vimeo、Bilibili、Twitter、TikTok、Facebook 等。
- 新增：支持加速下载，显著提升视频获取效率。
- 新增：支持剧集下载，可自动识别剧集列表并连续下载。
- 新增：支持批量下载，可同时处理多个视频任务。
- 新增：支持字幕选择与下载，可识别并自由选择多语言字幕轨。
- 新增：支持最高 4K 视频分辨率输出，获得更清晰画质。
- 新增：支持最高 320kbps 高品质音频输出，提升声音表现。
- 新增：支持 MP4 和 MKV 格式输出，兼容更多设备与播放器。
- 新增：支持 28 种语言的界面与内容识别，方便不同语言环境下使用。
