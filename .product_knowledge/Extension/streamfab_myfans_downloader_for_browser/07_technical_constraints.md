# 07 技术约束（Technical Constraints）

## 当前归档范围
- 本文件用于维护 MyFans 插件的技术约束与实现边界。

## 当前已知技术范围
- 浏览器插件
- 单站点产品
- 插件与客户端协同下载
- 输出格式：
  - `MP4`
  - `MKV`
- 音频：
  - `AAC 2.0`
- 分辨率：
  - `1080P`
  - `360P`

## 当前客户端拆解重点
- 检测依赖哪些页面条件
- 是否依赖播放态
- 下载配置从哪里返回
- 任务状态如何回传
- 是否存在明显的平台或客户端限制

## 产品页已确认的系统要求
- Windows `11/10 (32/64 bit)`
- `Intel i3 or above`
- `4GB RAM or above`
- `40GB` 可用硬盘空间
- 需要联网

## 客户端已确认的技术线索
- 下载配置项取决于当前视频分析结果。
- Meta 分析结果示例中包含：
  - `Resolution`
  - `Language`
  - `Subtitle`
- Setting 采用 common 配置项，不单独扩展特殊项。
