# StreamFab myfans Downloader for Browser

面向 MyFans（创作者订阅平台）用户的单站点浏览器下载插件，仅 Windows。

| 维度 | 取值 |
| --- | --- |
| 检测模式 | **netflix_mode** |
| 上线状态 | 集成中 |
| 站点 | `myfans.jp` |
| 地区 | region-agnostic（日本为主） |
| 视频画质 | 1080P（取决于源 + 账号权限 + MyFans plan） |
| 音频 | AAC 2.0 |
| 平台 | 仅 Windows |
| 价格 | $54.99 |
| Turbo Speed | 10X |
| 跳转 slug | `myfans` |
| 同类参考 | OnlyFans（同属创作者订阅模型） |
