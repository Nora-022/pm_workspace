# 02 功能架构（Functional Architecture）

## 架构范围
- 站点识别
- 资源检测
- 下载配置
- 下载任务创建
- 下载任务执行
- 客户端协同
- 授权与账号信息展示

## 主链路
1. 用户打开 MyFans 相关页面
2. 插件识别站点与可处理资源
3. 插件展示可下载内容
4. 用户选择下载项与配置
5. 插件创建任务
6. 客户端执行下载并回传状态
7. 插件在 Downloads 中展示结果

## 当前拆解重点
- 哪些页面会触发检测
- 资源识别单位是什么
- 下载配置项有哪些
- Detected 和 Downloads 的边界是什么
- 客户端与插件的状态回传有哪些

## 产品页已确认的链路信息
- 产品页步骤显示主链路为：
  1. 进入 `MyFans` 模块
  2. 登录 MyFans 账号
  3. 搜索并播放目标视频
  4. 配置输出分辨率、格式等参数
  5. 立即下载或加入 `Queue`
- 产品页明确提到：
  - 支持批量下载
  - 支持自动下载新发布内容
  - 支持多任务同时执行

## 客户端拆解已确认的链路信息
- 打开视频后自动分析 URL。
- 客户端存在分析视频界面和分析结果弹窗。
- 插件策略：
  - 去掉独立分析弹窗
  - 分析完成后将结果展示在插件内
- Meta 分析结果中的配置项为：
  - `Resolution`
  - `Language`
  - `Subtitle`
- Setting 无特殊配置项，采用 common 配置。
