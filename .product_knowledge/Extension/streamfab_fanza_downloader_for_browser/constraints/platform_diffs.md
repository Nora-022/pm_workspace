# constraints/platform_diffs.md

## Windows

- 支持 Windows 10/11（推荐 64 位）
- 依赖 CoApp 本地安装与后台运行

## macOS

- 当前不支持，显示 `MacOS unavailable`

## 浏览器渠道

- Chrome / Edge / 官网版本三渠道功能一致
- Fanza 无渠道间功能差异（与 ytdlp 不同，ytdlp 各渠道有差异）
