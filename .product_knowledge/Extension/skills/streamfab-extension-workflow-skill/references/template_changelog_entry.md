# Changelog 条目模板

## 产品版本条目格式

```
### {date} | 已发布 | {display_name} {plugin_version} + CoApp {coapp_version}

- 新增：{feature}
- 优化：{improvement}
- 修复：{fix}
```

## 知识库变更记录条目格式

```
### {date}
- 补充 `{filename}` {description}
- 更新 `{filename}` {description}
```

## 填写规则

- 产品版本条目写用户可见的变更（功能/修复），来源为飞书需求文档或官方更新页
- 知识库变更条目写知识库本身的更新，与产品版本无关
- 两部分在同一 CHANGELOG.md 中用 `---` 分隔
