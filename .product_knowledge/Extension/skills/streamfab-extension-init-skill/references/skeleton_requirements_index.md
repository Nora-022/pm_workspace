# 需求文档索引

## 本地工作文档

| 文档 | 文件 | 状态 | 说明 |
|---|---|---|---|
| 需求文档 | `plugin_requirement.md` | 已初始化 | 插件需求工作文档 |
| UI 需求说明 | `plugin_ui_requirement.md` | 已初始化 | 插件 UI 需求工作文档 |
| 客户端方案拆解 | `[RecordFab] - [客户端方案拆解] - {display_name}.md` | 待填写 | 由产品或客户端负责人填写，填写完成后进入后续 workflow |

## 使用规则

- 新模式下不创建飞书模板文档，三份文档均使用本地 Markdown。
- 初始化完成后，优先请用户填写客户端方案拆解 MD。
- 用户确认填写完成后，再由 `streamfab-extension-workflow` 读取本地 MD 并继续回填知识库。
