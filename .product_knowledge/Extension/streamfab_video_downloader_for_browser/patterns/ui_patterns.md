# patterns/ui_patterns.md

## 页面模式清单

### 模式 1：Detected 视频卡片
- 使用场景：展示当前页面识别到的可下载视频。
- 关键元素：
  - Checkbox
  - 缩略图与平台图标
  - 标题、时长、规格信息
  - 下载前配置区域
  - 单项 `Download`
- 设计重点：
  - 结果按检测时间倒序展示。
  - 配置项与视频信息保持在同一张卡片的上下文中。

### 模式 2：Downloads 任务卡片
- 使用场景：展示下载任务状态和操作。
- 关键元素：
  - 任务标题
  - 进度条
  - 速度 / 大小 / 状态
  - `Cancel` / `Retry` / `Open Folder`
- 设计重点：
  - 状态与操作同位。
  - 错误信息在卡片内就地反馈。

### 模式 3：顶部用户信息模块
- 使用场景：`Detected` 与 `Downloads` 顶部公共区域。
- 试用用户展示：
  - 头像
  - 邮箱
  - 剩余试用次数
  - `Trial`
  - `Buy Now / Upgrade`
- 订阅用户展示：
  - 头像
  - 邮箱
  - 订阅类型
  - Dashboard 入口

### 模式 4：视频下载设置弹窗
- 使用场景：单视频或多视频下载前统一配置。
- 设计稿中已明确可见：
  - `Format`
  - `Video Codec`
  - `Audio Codec`
  - `Subtitle`
- 设计重点：
  - 同时适用于单条与多条内容。
  - 底部有统一 `Download` 按钮。

### 模式 5：Playlist / 剧集选择弹窗
- 使用场景：Playlist、多视频或剧集内容的批量选择。
- 关键特征：
  - 保留层级结构。
  - 支持批量勾选。
  - 与下载前设置配合使用。

### 模式 6：商业阻断弹窗
- 使用场景：试用耗尽、订阅过期、当日额度不足。
- 关键要求：
  - 阻断下载动作。
  - 明确说明原因。
  - 提供清晰下一步。

### 模式 7：能力受限提示卡
- 使用场景：DRM 内容、Chrome 商店版 YouTube 限制、站点不支持。
- 关键要求：
  - 先解释为什么不能下载。
  - 再给替代方案或引导。

### 模式 8：状态页 / 特殊页
- 设计稿明确出现：
  - 检测中
  - 新增内容加载中
  - 空状态
  - 未登录
  - 未安装 CoApp
  - CoApp 有更新
  - 已安装 CoApp 但未检测到内容
