# Video Downloader 产品简介摘要

主文件：`../01_product_brief.md`

用于快速加载 Video Downloader 的定位与边界；完整内容以 `01_product_brief.md` 为准。

## 快速摘要
- 产品名称：StreamFab Video Downloader for Browser
- 一句话定位：面向流媒体用户的多站点浏览器下载插件
- 产品角色：产品线通用基础款，奠定后续单站点插件的产品框架与 UI 结构
- 支持范围：`yt-dlp` 支持的多站点视频下载，支持 Popup / Sidebar、`Detected / Downloads`、下载配置弹窗等基础框架
- 商业方案：`Lifetime Free Access（免费） / 30-Day Free Trial（免费；每服务 3 个视频） / 1-Year License $49.99 / Lifetime License $59.99`
- 主要边界：Chrome 版本不做 YouTube 下载；插件不做 DRM 视频下载
