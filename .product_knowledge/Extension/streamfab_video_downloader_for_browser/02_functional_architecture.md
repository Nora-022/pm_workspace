# 02 功能架构详解（Functional Architecture）

## 功能模块总览
- 模块 1：界面框架与展示模式
- 模块 2：视频分析与识别
- 模块 3：下载前配置与批量选择
- 模块 4：视频下载与任务队列
- 模块 5：账号试用与授权

## 模块规格（输入 / 处理 / 输出 / 异常）

### 模块：界面框架与展示模式
- 输入：用户打开插件。
- 处理：
  - 插件支持两种展示方式：
    - Popup
    - Sidebar
  - 两种模式复用同一套主框架：
    - `Detected`
    - `Downloads`
- 输出：
  - Popup：适合快速查看与快速发起下载。
  - Sidebar：适合持续查看检测结果与下载队列。
- 异常：
  - 模式切换不应改变功能结构。
  - 模式切换后应保持主要信息架构一致，避免用户重新学习。

### 模块：视频分析与识别
- 输入：视频 URL、当前网页上下文。
- 处理：
  - 调用开源 `yt-dlp` 代码库解析 URL。
  - 在 `Detected` 页展示当前页面识别到的视频结果。
- 输出：
  - 成功：返回分析结果，并在界面展示视频卡片。
  - 失败：
    - 当前界面无历史数据时：展示“未检测到视频”。
    - 当前界面有历史数据时：不新增数据（即代表本次检测失败）。
- 异常：
  - 站点不支持（DRM）：引导用户下载/试用 StreamFab 客户端。
  - 站点不支持（非 DRM 且 `yt-dlp` 不支持）：提示“未检测到视频，请确保视频播放或者刷新页面，部分网站可能不支持。”
  - 设计稿中可见的相关状态包括：
    - 检测中
    - 新增内容加载中
    - 空状态
    - 未登录
    - 已安装 CoApp 但未检测到内容

### 模块：下载前配置与批量选择
- 输入：已识别的视频结果、用户下载配置。
- 处理：
  - 在视频卡片内或独立弹窗中配置下载参数。
  - 多视频场景下支持统一配置后批量下载。
  - Playlist / 剧集场景下支持进入二级弹窗选择内容。
- 输出：
  - 单视频下载配置。
  - 批量下载配置。
  - Playlist / 剧集选择结果。
- 补充说明：
  - 设计稿中明确可见的配置维度至少包括：
    - `Format`
    - `Video Codec`
    - `Audio Codec`
    - `Subtitle`
- 异常：
  - 配置项不可用时，应保持结构稳定，不应打断主要流程。

### 模块：视频下载与任务队列
- 输入：视频 URL、用户 token 等授权信息、用户下载配置。
- 处理：
  - 插件将任务信息传给本地 CoApp。
  - CoApp 执行下载并回传处理进度。
  - `Downloads` 页负责展示任务队列、进度、失败重试与完成结果。
- 输出：
  - 下载中：插件界面展示进度。
  - 下载完成：界面通知任务完成，并展示结果。
- 异常：
  - 未安装/已卸载 CoApp。
  - CoApp 有更新。
  - 用户可下载任务数量小于发起任务数量：按任务排序过滤，仅放行可下载数量，其余任务拦截。
  - 试用用户可下载任务数 = 0：允许继续分析；点击下载时触发全局弹窗，提示试用机会用完并引导订阅。
  - 订阅用户场景拆分：`订阅已过期` 与 `订阅有效但当日额度为 0`。
  - `订阅有效但当日额度为 0` 时：允许继续分析；点击下载触发全局弹窗。文案："You've reached today's download limit (100). Downloads will be available again tomorrow." 按钮："Got it"（关闭弹窗）。

### 模块：账号试用与授权
- 输入：用户账号。
- 处理：在授权后台执行账号校验。
- 输出：授权结果、账号权益（试用次数、试用剩余天数、订阅账号剩余下载次数、订阅有效期）。
- 异常：
  - 网络错误（高频）：允许用户手动重试。
  - 授权上限（较高频）：引导去用户中心解除已绑定授权。
  - 其他授权失败：提示联系客户支持。

## 模块关系与依赖
- 前置依赖：账号试用与授权 -> 视频下载。
- 结构依赖：
  - `Detected` 负责当前页面的识别、选择与下载前配置。
  - `Downloads` 负责已创建任务的全局管理。
- 数据流向：
  - 视频分析：URL -> `yt-dlp` 解析 -> 结果回传插件界面。
  - 下载前配置：识别结果 -> 用户配置 -> 任务创建。
  - 视频下载：插件参数 -> CoApp -> 进度/结果回传插件界面。
- 与现有系统耦合点：
  - 开源 `yt-dlp` 解析能力。
  - 本地 CoApp 服务可用性。
  - 授权后台可用性与账号权益接口。
