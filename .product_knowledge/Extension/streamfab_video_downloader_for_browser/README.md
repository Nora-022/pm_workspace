# StreamFab Video Downloader for Browser

通用多站点浏览器下载插件，产品线 UX 与技术基线（首个上线插件）。

| 维度 | 取值 |
| --- | --- |
| 检测模式 | **ytdlp_mode**（基线活样例） |
| 上线状态 | 已上线 |
| 站点池 | yt-dlp 支持的 1000+ 站点 |
| 视频画质 | 最高 8K HDR |
| 音频 | 最高 320 kbps |
| 展示模式 | Popup + Sidebar 双模式 |
| 产品页 | https://streamfab.dvdfab.cn/streamfab-for-browser.html |
