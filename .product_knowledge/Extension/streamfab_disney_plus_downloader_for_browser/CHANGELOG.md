# Disney Plus Downloader for Browser Changelog

本文档记录 Disney Plus Downloader for Browser 的版本更新历史，按时间倒序整理。

## 版本历史

### 2026-03-16 | 已发布 | 1.0.0.1
- 新增：支持 Chrome 和 Edge，并全面兼容主流 Chromium 内核环境。
- 新增：支持下载 Disney Plus 的电影、剧集和电视节目。
- 新增：支持加速下载，显著提升视频获取效率。
- 新增：支持剧集下载，可自动识别剧集列表并连续下载。
- 新增：支持字幕选择与下载，可识别并自由选择多语言字幕轨。
- 新增：支持最高 4K 视频分辨率输出，获得更清晰画质。
- 新增：支持 H.264/H.265 视频编码选择，以兼顾播放器兼容性和压缩效率。
- 新增：支持保留 HDR10 / Dolby Vision 视频效果，在离线文件中保留更高动态范围。
- 新增：支持保留 EAC3 5.1 / AAC 2.0 音频，提升离线播放音质体验。
- 新增：支持 MP4 和 MKV 格式输出，兼容更多设备与播放器。
- 新增：支持 28 种语言的界面与内容识别，方便不同语言环境下使用。
