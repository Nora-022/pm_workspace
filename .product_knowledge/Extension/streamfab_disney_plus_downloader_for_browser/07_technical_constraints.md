# 07 技术约束（Technical Constraints）

## 系统与平台

- 当前知识库以 `Windows` 为主
- `macOS` 当前不支持或未开放

## 核心依赖

1. 已安装 CoApp
2. 账号授权成功
3. 账号有可下载次数
4. 可用次数在有效期内

## 检测 / 下载边界

- 无预分析
- 无跨 Origin
- 检测与下载可并行，`Downloading` 不阻断新检测
- `Detected` 上限 `50`

## 调度边界

- 批量发起
- 串行执行
- 并发 `1`
- `Retry` 回队头

## 配置边界

- 结果配置由接口返回驱动，不应写死静态值
- `Video Codec` 需要支持：
  - `H264`
  - `H265-SDR`
  - `HDR10`
  - `Dolby Vision`
- `Audio Codec` 需要支持：
  - `Atmos`
  - `EAC3`
  - `AAC`

## 文件体积边界

- Disney 代表的一类 VIP 服务可能拿不到文件大小
- 因此：
  - 视频卡片上的文件大小标签可能不存在
  - 下载中的进度信息可能需要用 `Segment` 表达

## 内容结构边界

- Extras 结构可能存在两层或三级结构
- 在插件空间受限情况下，是否压缩层级仍需确认

## 不应默认假设

- 不默认所有 Disney 内容都能拿到 `1080p`
- 不默认所有视频都存在文件大小信息
- 不默认 Extras 可安全打平而不损失内容语义
- 不默认 UI 宣传口径就等于插件最终可交付能力口径

## 待持续验证项

- 1080p 不可用时的提示时机
- Dashboard banner 的最终能力口径
- Extras 层级压缩是否可行
