# Requirements Archive

用途：集中存放该插件的需求文档，作为知识库补充与长期上下文。

## 目录说明
- `raw/`：原始需求文档（pdf/md/docx 等）
- `derived/`：从原始文档提取/清洗后的中间文件（txt、摘要、片段）
- `index.md`：需求文档清单与状态追踪

## 维护规则
1. 新需求先放 `raw/`
2. 若做解析或清洗，输出放 `derived/`
3. 在 `index.md` 记录：版本、日期、状态、关联知识库文件

## 文件结构
```text
requirements/
├── README.md                  ## 当前目录入口，说明需求文档的阅读方式与组织结构
├── index.md                   ## 需求索引，汇总正式需求文档与辅助资料入口
├── plugin_requirement.md      ## 正式需求文档，记录功能、规则、链接与关键产品定义
├── plugin_ui_requirement.md   ## UI 需求文档，记录界面结构、交互与展示要求
├── raw/                       ## 原始输入目录，保存历史文档、会议纪要与外部原始材料
└── derived/                   ## 整理输出目录，保存从原始资料提炼出的摘要、归纳与整理结果
```
