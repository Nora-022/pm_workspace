# OnlyFans 站点技术调研

## 基本信息

- 站点：`https://onlyfans.com/`
- 调研日期：`2026-04-28`
- 调研目的：支持 StreamFab OnlyFans Downloader 插件开发，了解站点内容类型、流媒体协议、DRM 方案、编解码格式与技术边界

---

## 1. 内容类型与访问路径

| 内容类型 | 访问路径 | DRM 保护 | 说明 |
|---|---|---|---|
| Post 视频 | 订阅或单次购买 | 创作者可选开关 | 发布在 Feed 中的公开或付费内容 |
| Message 视频（DM） | 私信付费解锁 | 通常有 DRM | 私信中发送的付费视频，权限比 Post 更严格 |
| Free 内容 | 无需订阅 | 通常无 DRM | 创作者设置为免费的内容 |

**关键区别**：DRM 保护为创作者级别的开关，并非全站统一强制。创作者可以按内容选择是否启用。Message 视频通常比 Post 视频携带更严格的 DRM。

---

## 2. 流媒体协议

- **主协议：HLS（M3U8）**
  - OnlyFans 主要使用 HLS 进行视频流交付
  - 视频分片以 fMP4（Fragmented MP4 / CMAF）格式封装
  - 自适应码率（ABR）：根据网络状况自动切换分辨率档
- **MPEG-DASH**：部分场景并行支持，但 HLS 为主流交付协议
- 访问 Token 有效期短，平台频繁轮换，过期后请求失败

---

## 3. DRM 方案

OnlyFans 采用多 DRM 策略，依平台选择：

| DRM 方案 | 适用平台 | 说明 |
|---|---|---|
| Widevine | Chrome / Firefox / Android | 浏览器侧为 L3（软件解密） |
| PlayReady | Edge / Windows | 硬件级支持 |
| FairPlay | Safari / iOS | 系统级限制，录屏通常黑屏 |

**浏览器侧关键约束：**
- Chrome / Firefox 使用 Widevine **L3**（纯软件），OnlyFans 在该级别允许最高 **1080P** 播放
- 与 Netflix 不同：Netflix 主动将 Widevine L3 限制在 720p，OnlyFans 官网明确支持到 1080P
- 2024 年底，OnlyFans 对部分高清内容加强了 DRM，转向更严格的加密策略，导致大量基于脚本抓取的工具失效
- Screen recording 通常触发浏览器级内容保护，录制结果为黑屏

**DRM 加密格式：**
- 使用 **Common Encryption（CENC）**，PSSH 中同时携带 Widevine 和 PlayReady 初始化数据
- 分片本身为 fMP4 + AES-128 / CTR 加密

## 4. 视频规格

| 维度 | 情况 |
|---|---|
| 最高播放分辨率 | **1080P（FHD）**，平台流媒体侧不渲染超过 1080P |
| 常见分辨率档位 | 1080P / 720P / 480P 及以下（依 ABR 梯级） |
| 视频编码 | H.264（主流），部分内容支持更新编码 |
| 音频编码 | AAC 2.0（官网确认） |
| 容器格式 | fMP4（流媒体），下载输出支持 MP4 / MKV |
| 上传规格限制 | 创作者上传：最大 10GB，建议 1080P H.264 MP4；平台不渲染超过 1080P，4K 上传会被转码至 1080P |

---

## 5. 反下载与内容保护机制

- **Token 轮换**：访问令牌频繁刷新，未实时跟踪的下载工具在接近完成时失败（99% 卡住现象）
- **录屏黑屏**：浏览器 EME（Encrypted Media Extensions）机制，DRM 内容屏蔽截图与录屏
- **私信权限隔离**：Message 视频的 DRM license 请求路径与 Post 视频不同，权限验证更严格
- **2024 底加固**：OnlyFans 将主流高清内容 DRM 加密升级，破坏了大量依赖直接抓取 URL 的方案；85% 以上基于 Chrome 扩展的下载工具成功率下降至 20% 以下（2025–2026 数据）

---

## 6. 平台订阅与内容权益

- 创作者独立设定订阅价格，无平台统一标准
- 付费内容路径：订阅 / 单次购买 / Tips 解锁
- 无平台级统一"会员制"，权限以账号登录态 + 内容购买状态校验

## 7. 与其他平台关键差异

| 维度 | OnlyFans | Netflix | Disney+ |
|---|---|---|---|
| DRM 强制范围 | 创作者可选（非全站强制） | 全站强制 | 全站强制 |
| 浏览器最高分辨率 | **1080P** | 720P（Widevine L3 限制） | 1080P |
| 内容类型 | UGC（用户生成） | PGC（专业制作） | PGC |
| 流媒体协议 | HLS 为主 | MPEG-DASH 为主 | HLS + CMAF |
| Token 稳定性 | 短有效期、频繁轮换 | 相对稳定 | 相对稳定 |

## 8. 对插件开发的技术含义

- **无跨 Origin 需求**：OnlyFans 视频资源同域，不需要跨 Origin 检测能力
- **Token 实时跟踪**：下载流程需实时刷新访问令牌，否则易在高进度阶段失败
- **DRM 解密路径**：需通过 CoApp 处理 Widevine license 请求，浏览器扩展自身无法完成解密
- **Message 视频单独适配**：其 DRM license 路径、权限校验与 Post 视频有差异，需单独处理
- **分辨率上限确认**：1080P 为平台侧实际上限，无需适配 4K 流
