# 01 产品简介（Product Brief）

## 产品名称
- StreamFab OnlyFans Downloader for Browser

## 一句话定位
- 面向 OnlyFans 用户的专用下载工具，支持 Message videos 和 DRM video 下载。

## 核心用户
- 有离线观看需求的 OnlyFans 用户

## 核心功能清单
1. OnlyFans 视频下载（含 Message videos 和 DRM video）
2. 最高 FHD 1080P，支持 Original / 720p / 480p 分辨率选择（由 meta 驱动）
3. 视频编码：H.264 / H.265
4. 音频：AAC 2.0（Stereo）/ EAC3 5.1
5. 输出格式：MP4 / MKV（FFmpeg）/ MKV（MKVToolNix）
6. 元数据保存（title / season / episode / cast / poster）
7. 批量下载 + 队列管理
8. 定时 / 自动下载（按天 / 按周）
9. region-agnostic：下载账号有权限观看的任意区域内容
10. 去广告处理（对含广告计划内容进行无广告导出）

## 产品红线
- 不支持 OnlyFans 以外站点
- 不在未登录情况下放行有效下载
- 仅供用户个人合法使用
- macOS 暂不支持（计划支持，当前仅做 Windows）
