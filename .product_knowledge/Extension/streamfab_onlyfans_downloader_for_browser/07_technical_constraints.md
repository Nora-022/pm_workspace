# 07 技术限制与约束（Technical Constraints）

## 系统与平台
- Windows 11 / 10（32/64 bit）：已支持
- macOS：计划支持，当前版本暂只做 Windows
- 处理器：Intel i3 或以上
- 内存：4GB 及以上
- 硬盘：40GB 以上可用空间
- 需要网络连接

## 分发渠道（待确认）
- Chrome / Edge / 官网版本
- 渠道差异待确认

## 能力边界
- 仅支持 OnlyFans 站点
- 支持 Message videos 和 DRM video（官网明确）
- 检测与下载可并行，Downloading 不阻断新检测（预设）
- 串行执行（并发 1）（预设）
