# 产品简介摘要

- **产品名**：StreamFab M3U8 Downloader
- **定位**：多站点 M3U8 / HLS 视频下载插件，不绑定特定平台
- **支持加密**：明文、AES-128、AES-256、SAMPLE-AES（key 从 `#EXT-X-KEY` 直接提取）
- **不支持**：Widevine / PlayReady / FairPlay 等 DRM 加密
- **页面结构基线**：Netflix 类插件
- **浏览器**：Chrome、Edge（Chromium 内核）
- **平台**：Windows、macOS（均有 CoApp）

完整信息见 `01_product_brief.md`。
