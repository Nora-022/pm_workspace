## 产品定位

- **产品名**：StreamFab M3U8 Downloader for Browser
- **一句话定位**：下载任意网站的 M3U8 / HLS 协议视频，最高 1080P，明文与 AES 加密通吃
- **多站点**：不绑定特定平台，任意含 M3U8 流的视频站点均在范围内

## 能力清单（CHANGELOG V1001）

- 支持 Chrome 与 Edge，全面适配主流 Chromium 内核环境
- 下载任意 M3U8 站点的剧集 / 电影
- 支持加速下载
- 支持剧集下载，自动识别剧集列表并连续下载
- 支持字幕选择与下载，可识别多语言字幕轨道
- 视频分辨率：产品页与 License Info banner 口径为 **1080P**
- 视频编码：H.264 / H.265
- 音频：EAC3 5.1 / AAC 2.0
- 输出格式：MP4 / MKV
- 28 种语言界面
