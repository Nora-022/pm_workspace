# Product Brief (Context Summary)

> Distilled from `01_product_brief.md` and `07_technical_constraints.md`. Do not introduce new facts here — keep this file aligned with the core files.

## Identity
- Product name: `StreamFab Hulu Downloader for Browser`
- Type: single-site browser plugin
- Target sites: `https://www.hulu.com/` and `https://www.hulu.jp/`

## Capability Surface
- Outputs: `MP4`, `MKV`
- Video codec selectable: `H.264`, `H.265`
- Resolution: up to `1080p/4K` (product-page promise)
- Audio: `EAC3 5.1` (product-page promise)
- Region-agnostic download for content the user has access to
- Preserves metadata: `title`, `season`, `episode`, `cast`, `poster`

## Platform
- Windows: priority for current release
- macOS: declared, not delivered in this release
