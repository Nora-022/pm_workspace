# StreamFab Hulu Downloader for Browser

面向 Hulu 用户的双地区双站点浏览器下载插件。

| 维度 | 取值 |
| --- | --- |
| 检测模式 | **netflix_mode** |
| 上线状态 | 待研发 |
| 站点 | `hulu.com`（美国）+ `hulu.jp`（日本） |
| 视频画质 | 1080p / 4K |
| 编码 | H.264 / H.265 |
| 音频 | EAC3 5.1 |
| 输出格式 | MP4 / MKV |
| 平台 | 当前发布 Windows；macOS 已声明未交付 |
| 价格 | 1M $59.99 / Lifetime $109.99 |
| 跳转 slug | `hulu-downloader` |
| 产品页 | https://streamfab.com/hulu-downloader.htm |
