# 00 概览

## 产品定位
- 产品名称：StreamFab Hulu Downloader for Browser
- 产品类型：独立单站点浏览器插件
- 支持范围：Hulu 相关流媒体服务

## 已确认事实
- 客户端产品页：`https://streamfab.com/hulu-downloader.htm`
- 目标站点：`https://www.hulu.com/`、`https://www.hulu.jp/`
- 产品页明确宣传 `1080p/4K` 下载、`MP4` 输出与 `EAC3 5.1 audio track`
- FAQ 显示：30 天试用、试用期可下载 3 个 Hulu 视频、每天最多下载 100 个 Hulu 视频
- 客户端调研已确认：部分标题采用 season / episode 树；部分标题存在字幕版 / 配音版分流；当前右侧面板仅暴露视频质量
