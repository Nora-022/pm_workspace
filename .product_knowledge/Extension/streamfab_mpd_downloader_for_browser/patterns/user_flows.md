# 用户流程（patterns/user_flows）

## 主流程：检测 → 下载

1. 用户已安装 StreamFab DRM MPD Coapp 并在插件中登录授权
2. 在受 DRM 保护的 MPD 站点页面打开视频
3. 插件**自动分析当前 URL**（无独立分析弹窗）
4. 识别为 MPD + DRM 内容后，DRM MPD 标识显示并点亮下载按钮
5. 用户点击下载按钮 → 弹出 Meta 分析结果弹窗（视频标题、Resolution、Language、Subtitle）
6. 用户选择配置后确认下载
7. 任务进入串行队列（FIFO），并发 1
8. 下载中显示：分辨率标签 + 速度 + 进度 + 分片进度
9. 下载完成后状态切到 "下载成功"，标签改为 分辨率 + 音频编码 + 文件大小

## 分支流程

### 不支持的内容

- 站点非 MPD / 内容未识别为 DRM 加密 → 下载按钮保持灰色不点亮
- 用户无操作

### 分析失败

- Meta 分析未返回完整字段 → 提示分析失败，不进入 Meta 弹窗

### 登录中断

| 当前状态 | 处理 |
|---|---|
| Detected 有视频 | 不允许启动新任务，提示登录 |
| Detected 为空 | 提示登录 |
| Downloading | 允许继续 |
| Failed | 禁止重试 |
| Downloaded | 保留展示 |

### 配额耗尽

- Trial 用户达到 3 次 → 试用弹窗提示升级（与 Netflix 一致）
- Premium 用户达到当日 100 / 当周 700 → 提示已达上限
