# 04 交互细节（Interaction Details）

> 基线插件：Netflix。本文档仅记录差异点。

## 前置条件

- 已安装 CoApp
- 账号已登录并授权成功
- 账号有可用次数（Trial 3 个 / Premium 100 日 / 700 周）

## 检测流程

- 用户在 MPD DRM 站点打开视频页面后，插件**自动分析当前 URL**，无独立分析弹窗
- DRM MPD 标识默认不展示；分析完成识别为 MPD + DRM 内容后，下载按钮点亮
- 点击下载按钮 → 弹出 Meta 分析结果弹窗（视频标题、Resolution、Language、Subtitle）
- 用户在弹窗中选择配置后确认下载

## 下载调度

- 串行执行（并发 1）
- 队列 FIFO
- Retry 回队头，按当前余量重新判断

## Downloading 界面信息

| 任务状态 | 标签展示 | 附加信息 |
|---|---|---|
| 待下载 / 下载成功 | 分辨率 + 音频编码 + 文件大小 | — |
| 排队下载 | 仅分辨率 | — |
| 下载中 | 仅分辨率 | 速度、进度、分片进度 |
| 下载失败 | 仅分辨率 | — |

## 登录中断后的行为

| 当前状态 | 处理 |
|---|---|
| Detected 有视频 | 不允许启动新任务，提示登录 |
| Detected 为空 | 提示登录 |
| Downloading | 允许继续 |
| Failed | 禁止重试 |
| Downloaded | 保留展示 |

## 错误与异常处理

参照 Netflix 基线的错误处理矩阵；本插件无差异化错误场景。
