# 参考资料目录（_common/references）

本目录只存放非规范资料：原始调研、外部证据、历史方案和竞品分析。

现行规则不写在这里。所有当前生效的 common 规则必须写入 `_common/01+` 编号文件。

## 文件清单

| 文件 | 内容 |
| --- | --- |
| `index.md` | 参考资料索引 |
| `vdh_v10_coapp_research_and_streamfab_options.md` | VDH v10 CoApp 调研与 StreamFab 方案评估 |
| `vdh_v10_competitor_strategy_research.md` | VDH v10 竞品策略调研 |

## 允许放入

- 竞品调研
- 外部资料摘要
- PoC 记录
- 历史方案与迁移背景
- 形成规则前的证据材料

## 不允许放入

- 当前生效的业务规则
- 当前生效的检测模式基线
- 当前生效的 UI / UX / 视觉 / 布局规范
- 当前生效的技术限制
- 当前生效的错误处理、配额、授权、状态机
