## 字段说明

| 字段 | 含义 |
| --- | --- |
| 插件版本 | 浏览器扩展包版本号（如 V1005 或 1.0.0.9） |
| CoApp 版本 | 与该插件版本配对的 CoApp 版本号 |
| 发布日期 | 该版本封版日期 |
| 状态 | 已发布 / 已封版 / 集成中 / 待研发 |

## 同步规则

- 飞书多维表格是权威来源，本地是快照
- 同步时整张表覆盖更新，不做增量合并
- 同步后在表头标注同步日期
- 不在本表维护 URL / 下载链接 / 渠道差异（这些字段在飞书表中，本地不复制）
