# Product Brief — StreamFab U-NEXT Downloader for Browser

- **产品名**：StreamFab U-Next Downloader for Browser
- **app_id**：streamfab_for_browser_u-next
- **CoApp 名**：StreamFab U-Next Coapp
- **定位**：面向 U-NEXT / H-NEXT 用户的浏览器下载插件，支持最高 4K DRM 视频离线保存
- **目标站点**：video.unext.jp（U-NEXT）、H-NEXT（U-NEXT 账号下的成人内容分支）
- **分发渠道**：Chrome / Edge / 官网，功能一致
- **核心能力**：最高 4K / 1080P，H.264 / H.265，EAC3 5.1 / AAC 2.0，MP4 / MKV，字幕（SRT 或内嵌），批量下载 TV 剧集
- **加密支持**：U-NEXT DRM 保护视频
- **核心流程**：直接复用 Netflix 插件流程
