# 07 技术限制与约束（Technical Constraints）

## 系统与平台

| 平台 | 支持 | 最低要求 |
|---|---|---|
| Windows | ✅ | Win 11/10（32/64 bit），Intel i3+，4GB RAM，40GB 磁盘 |
| macOS | ✅ | macOS 11.0+，Core 2 Quad+，4GB RAM，40GB 磁盘 |

## 分发渠道
- Chrome / Edge / 官网版本
- 三渠道功能一致

## 核心依赖
1. 已安装 CoApp
2. 账号授权成功
3. 账号有可下载次数
4. 可用次数在有效期内

## 能力边界
- 支持站点：U-NEXT、H-NEXT
- 最高分辨率：4K / 1080P
- 视频编码：H.264、H.265
- 音频：EAC3 5.1、AAC 2.0
- 输出格式：MP4、MKV
- 字幕：外部 SRT 或内嵌
