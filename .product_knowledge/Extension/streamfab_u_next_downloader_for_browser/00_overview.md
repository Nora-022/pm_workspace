# 00 概览

## 产品定位
- 产品名称：StreamFab U-NEXT Downloader for Browser
- 产品类型：独立单站点组插件（U-NEXT + H-NEXT 同属一个插件）
- 支持范围：`video.unext.jp`（U-NEXT）、`h-next.com`（H-NEXT 成人内容分支）
- 当前阶段：集成中

## 已确认边界
- 目录命名：`streamfab_u_next_downloader_for_browser`
- 服务标识：`u_next`
- 对外显示名称：`U-NEXT`
- app id：`streamfab_for_browser_u-next`
- pid（Win / Mac）：659 / 1659
- 最高分辨率：4K（由 CoApp 分析结果决定，Settings 预设上限 1080p）
- 核心技术基线：参照 Netflix 插件，差异见 `02_functional_architecture.md`
