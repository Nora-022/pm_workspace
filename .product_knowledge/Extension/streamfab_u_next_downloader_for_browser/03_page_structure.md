# 03 页面结构（Page Structure）

## 主要页面

1. Dashboard（含 License Info）
2. Settings
3. Detected（U-NEXT 检测结果）
4. Downloads

## Dashboard — License Info Banner

| 字段 | 内容 |
|---|---|
| Banner EN | Download U-NEXT DRM Videos, Made Simple. / Save U-NEXT and H-NEXT videos offline in up to 4K with EAC3 5.1 or AAC 2.0 audio. |
| Banner ZH | 轻松下载 U-NEXT DRM 视频。/ 将 U-NEXT 和 H-NEXT 视频以最高 4K 分辨率下载到本地，并支持 EAC3 5.1 或 AAC 2.0 音频格式。 |

## Settings 配置项（按顺序）

| 序号 | 配置项 | 附属子项 |
|---|---|---|
| 1 | Language | — |
| 2 | Video Format | — |
| 3 | Video Resolution | — |
| 4 | Pre-select Audio Language | Pre-select Description Audio |
| 5 | Audio Channel | Pre-select both 5.1 and 2.0 |
| 6 | Pre-select Subtitle Language | Always download forced subtitle |
| 7 | Subtitle Action | — |

与 Netflix 插件一致，无 U-NEXT 差异化配置项。

## Detected 页面

- 展示从 video.unext.jp / H-NEXT 检测到的视频卡片
- 支持批量发起 TV 剧集下载
- 下载配置选项：Resolution + Language

## Downloads 页面

- 下载中展示：文件大小 / 速度 / 已完成进度（非分片数）
