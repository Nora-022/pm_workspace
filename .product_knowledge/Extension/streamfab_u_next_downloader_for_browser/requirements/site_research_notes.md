# Site Research Notes

用于沉淀 U-NEXT 插件目标站点调研结果，在正式初始化 `00-07` 和需求文档前，先记录站点侧的确定性信息、约束和待确认问题。

## 调研结论总览

- `U-NEXT` 是主站点，提供常规视频内容。
- `H-NEXT` 是 U-NEXT 体系内的成人内容服务。
- `H-NEXT` 已不再直接包含在 U-NEXT 月额套餐内，而是单独的 `H-NEXT见放题服务`。
- 常规 U-NEXT 视频通常需要登录后观看。
- 部分 U-NEXT 免费直播活动存在“不登录也可观看”的例外，但这不代表常规点播内容可匿名播放。

---

## 1. U-NEXT

### 1.1 站点基本信息
- 站点名称：U-NEXT
- 主站 URL：<https://www.video.unext.jp/>
- 调研日期：2026-03-19

### 1.2 站点定位与内容范围
- 主内容类型：电影、剧集、动画、综艺、直播等综合视频服务
- 账号体系：完整的 U-NEXT 账号与月额方案体系
- 关联服务：存在成人内容相关的 `H-NEXT`

### 1.3 账号与会员要求
- 常规点播内容：通常需要登录后观看
- 月额方案：官方帮助页显示 U-NEXT 月额为 `2,189円`
- 免费例外：部分官方免费直播活动，明确写过“没有 U-NEXT 账号也可以观看”

### 1.4 播放与检测前提
- 对常规视频插件检测来说，应默认：
  - 需要进入内容详情或播放页
  - 需要登录账号
  - 很可能需要触发实际播放后，才能拿到更完整的媒体信息
- 是否必须开播后才稳定暴露媒体请求，仍需后续实测

### 1.5 对插件设计的影响
- 前置引导态至少需要考虑：
  - 未登录
  - 非会员 / 无可播放权限
  - 未进入播放页
  - 未开始播放
- 不应把“免费直播可匿名观看”推广为主站常规播放规则

### 1.6 依据来源
- U-NEXT 官方帮助页：免费直播存在“无账号也可观看”的说明
  - 来源：<https://help.unext.jp/info-video/detail/info031b>
- U-NEXT 官方帮助页：月额方案说明
  - 来源：<https://help.unext.jp/info/info916>

## 2. H-NEXT

### 2.1 站点基本信息
- 站点名称：H-NEXT
- 服务关系：U-NEXT 体系内的成人内容服务
- 当前可确认入口 URL：
  - 官方帮助说明页：<https://help.unext.jp/guide/detail/whats-hnext-service>
  - U-NEXT 主站：<https://www.video.unext.jp/>
- 备注：暂未确认一个稳定、独立的公开 H-NEXT 前台主页 URL，后续如发现实际播放或内容入口页，再补充
- 调研日期：2026-03-19

### 2.2 站点定位与内容范围
- 内容定位：成人内容
- 产品归属：不是完全独立于 U-NEXT 账号体系的新产品，而是挂在 U-NEXT 体系下的独立服务包

### 2.3 账号与会员要求
- 官方帮助页明确说明：
  - `H-NEXT见放题服务` 是“月额方案用户专用的包”
  - 观看时需要按页面提示购买“31 天包”
- 这意味着：
  - 要看 H-NEXT，至少需要 U-NEXT 账号登录
  - 且需要额外购买 H-NEXT 服务包

### 2.4 定价与套餐关系
- H-NEXT 见放题服务价格：`440円`
- 计费周期：`31天`
- 官方说明：购买 H-NEXT 包后，会对当月 U-NEXT 月额做 `440円` 返还
- 官方帮助页给出的最终说明：
  - `2,189円` 可同时享受 `月额方案` 与 `H-NEXT见放题服务`

### 2.5 播放与检测前提
- 对 H-NEXT 插件支持来说，应默认：
  - 需要登录 U-NEXT 账号
  - 需要具备 H-NEXT 对应可观看权限
  - 可能还存在年龄确认或支付相关限制
- H-NEXT 内容与普通 U-NEXT 内容在前置引导和权限提示上应区分处理

### 2.6 对插件设计的影响
- 支持范围文案中如果写到 H-NEXT，必须同步体现其权限前提
- 插件引导态建议额外考虑：
  - 已登录 U-NEXT，但未开通 H-NEXT 包
  - 已登录但受年龄/支付限制
- 业务规则上不能把 U-NEXT 和 H-NEXT 简单视为同一权益层级

### 2.7 依据来源
- 官方帮助页：
  - `H-NEXT见放题服务` 已于 `2024-06-21` 起从 U-NEXT 月额方案中切离
  - 观看时需要购买 `31日间` 服务包
  - 价格为 `440円`
  - 来源：<https://help.unext.jp/guide/detail/whats-hnext-service>

## 3. 当前可确定的插件范围判断

- 插件宣传层面可以写“支持 U-NEXT / H-NEXT”
- 但产品规则层面必须拆开看：
  - `U-NEXT`：常规主站内容
  - `H-NEXT`：额外成人内容服务包

因此后续文档建议固定写法：
- 支持范围：`U-NEXT 及 H-NEXT`
- 权限说明：`H-NEXT 需要在 U-NEXT 账号体系下额外具备对应服务包权限`

## 4. 待确认问题

- U-NEXT 常规点播是否必须实际点击播放后才暴露稳定媒体请求
- H-NEXT 是否使用与 U-NEXT 完全一致的播放页结构
- H-NEXT 是否存在独立的年龄确认弹层、支付确认弹层或独立播放器差异
- U-NEXT / H-NEXT 的字幕、音轨、清晰度在页面层是否能直接观察到明显差异
