# PlayOn 竞品调研（2025–2026）

## 背景

PlayOn 是美国 MediaMall Technologies 出品的流媒体录制产品，是市场上少数真正落地了"云端录制"的竞品。本文记录其 2025 至 2026 年的产品现状、迭代重点与商业模式，重点关注云录制方向对 RecordFab 的参考价值。

---

## 一、产品双线格局

PlayOn 目前维护两个并行产品，战略重心已明显向 Cloud 倾斜：

| | PlayOn Home | PlayOn Cloud |
|---|---|---|
| 平台 | Windows PC | iOS / Android / Android TV |
| 录制方式 | 本地实时屏幕录制 | 服务器端云录制（虚拟机实时播放） |
| 分辨率 | 最高 720p | 最高 1080p（消耗更多积分） |
| 定价 | $39.99/年 或 $14.97/季 | 积分制：每月含 30 积分；SD 录 1 积分，1080p 录 3 积分 |
| 云存储 | 无 | 7 天免费，付费方案可延长 |
| 现状 | 更新停滞，用户投诉多 | 主力产品，持续维护 |

---

## 二、2025–2026 关键更新

**实质性进展只有一件事**：PlayOn Home 1080p FHD 录制（2023 年底上线，2025 持续推广）。官方自称"上线以来用户呼声最高的功能"，但需同时订阅 PlayOn Cloud 计划才能解锁，是把 Home 用户引导绑定到 Cloud 订阅的钩子。

2025–2026 没有明显新功能上线。PlayOn Home 版本号至 5.0.352（2026-02-27 更新），更新内容基本全是平台兼容 bugfix。博客最新内容停在 2024 年 8 月。

---

## 三、PlayOn Cloud 商业模式拆解

PlayOn Cloud 是技术路线上的"服务端云录制"落地案例：

- **虚拟机实时播放录制**：云端机器实际登录用户账号、播放视频、录屏
- **积分制控制成本**：用户预购云计算时间；1080p 消耗 3 倍积分，精确控制算力成本
- **7 天云存储即删**：大幅压低存储成本
- **用户自带账号**：RecordFab 不承担内容版权责任

**实际口碑**：Trustpilot 评分 1.4/5（88% 一星），主要投诉：录制失败频繁、广告跳过不准、App 崩溃、终身授权被单方面取消。

---

## 四、产品弱点

- **服务端录制可靠性差**：云端机器面对平台反录制策略、账号风控、网络波动，比本地更脆弱
- **PlayOn Home 720p 天花板**：屏幕录制限制，无法突破
- **桌面端被放弃**：用户普遍反映 Home 版本"被开发者遗忘"
- **积分失败不退**：录一半失败，积分照扣，是最集中的投诉点

---

## 五、对 RecordFab 的参考价值

**验证了需求**：PlayOn Cloud 的核心价值命题"用户不需要守着录"是真实市场需求，用户愿意为此付费。

**验证了服务端方案的代价**：PlayOn 证明纯服务端录制在可靠性上有结构性弱点——账号风控、平台反制、网络抖动都会导致任务失败，且用户体验代价高。

**RecordFab 本地定时录制的优势**：用户不需要守着（体验等同），但录制在本机执行，稳定性远优于云端虚拟机。S2 定时录制方向定位准确，重点要做好任务成功率和失败通知机制——这恰好是 PlayOn 做烂的地方。
