# 04 交互细节（Interaction Details）

## 开始录制
- 触发方式：用户在集成浏览器内进入目标视频页面后，点击 `Start`。
- 前置条件：
  - 已检测到可录制视频流
- 流程：
  1. 系统检测可录制视频流
  2. 用户设置输出分辨率、录制速度和自定义录制时间
  3. 用户确认后开始录制

## 录制前配置弹窗
- 当前共有 3 个参数：
  - 输出分辨率
    - 可选项：`1080` / `720`
    - 含义：输出分辨率，不代表源视频的实际分辨率
    - 当前规则：允许低转高，但清晰度不会真的变高
  - 录制速度
    - 可选项：`1` / `2` / `3` / `4` / `5`
    - 含义：对应 `1x` / `2x` / `3x` / `4x` / `5x` 倍速录制
  - 自定义录制时间
    - 默认关闭
    - 开启后显示时间输入框
    - 输入单位为分钟
    - 默认值为 `2`
    - 到时后自动结束录制

## 录制中
- 录制时视频播放界面有遮罩层。
- 用户无法直接操作视频内容。
- 页面主要展示：
  - 已录制时长
  - 当前速度
  - `Stop`
- 不支持暂停。
- 不支持继续。
- 用户只能点击 `Stop`，或强制关闭产品。

## 停止录制
- 点击 `Stop` 后：
  - 结束当前录制
  - 录制遮罩消失
  - 视频播放页恢复正常
  - `My Files` Tab 显示数字气泡 `1`
- 默认不自动跳转到 `My Files`

## 自动结束录制
- 当用户开启“自定义录制时间”后，到达设定时间会自动结束录制。
- 自动结束后的页面结果与手动点击 `Stop` 一致：
  - 遮罩消失
  - 当前页恢复正常
  - `My Files` 显示新增文件气泡

## 查看结果
- 用户点击 `My Files` 后查看新增文件。
- 新增文件显示为视频卡片。
- 卡片展示：
  - 时长
  - 文件大小
  - 输出分辨率
  - 打开文件夹 icon
- 点击打开文件夹 icon 会打开本地目录。

## 失败处理
- 录制失败后不支持一键重试。
- 用户需重新播放视频并重新发起录制。

## 其他限制
- RecordFab 内其他操作会在录制中被限制。
- 内部测试资料提到：最小化到后台时录制仍可正常进行。
