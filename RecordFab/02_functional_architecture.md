# 02 功能架构详解（Functional Architecture）

## 功能模块总览
- 模块 1：内容发现与站点访问
- 模块 2：视频检测与录制参数设置
- 模块 3：录制执行与状态反馈
- 模块 4：输出保存与结果管理

## 模块规格（输入 / 处理 / 输出 / 异常）

### 模块：内容发现与站点访问
- 输入：用户访问目标站点的意图、账号登录信息、目标视频页面。
- 处理：
  - 通过集成浏览器访问目标站点。
  - 用户在产品内完成登录、浏览和选片。
- 输出：
  - 成功：进入目标内容播放页。
  - 失败：停留在浏览器容器中，等待用户重新登录或重试访问。
- 异常：
  - 站点登录失败
  - 页面无法加载
  - 网络连接异常

### 模块：视频检测与录制参数设置
- 输入：正在播放的视频流、用户选择的分辨率和录制速度。
- 处理：
  - 自动检测视频流。
  - 允许用户配置输出分辨率和录制速度。
- 输出：
  - 成功：任务进入待录制状态。
  - 失败：提示未检测到可录制内容或当前站点能力受限。
- 异常：
  - 未检测到视频流
  - 当前站点仅支持 1x 录制
  - 目标内容无法稳定开始录制

### 模块：录制执行与状态反馈
- 输入：待录制任务、录制参数、系统资源。
- 处理：
  - 启动录制任务。
  - 在录制过程中禁用部分其他操作，优先保障录制稳定性。
  - 持续反馈进行中状态。
  - 内部资料显示录制流程可拆为：
    - `Prepare`：录制准备，开始获取浏览器中的 YUV 数据
    - `Recording`：持续截获播放中的数据
    - `Remux`：录制结束后加工输出成用户要求的视频文件
- 输出：
  - 成功：录制完成。
  - 中断：用户手动停止。
  - 失败：录制终止并给出错误反馈。
- 异常：
  - 网络中断
  - 系统资源不足
  - 站点兼容性波动

### 模块：输出保存与结果管理
- 输入：录制完成的视频数据。
- 处理：
  - 将结果保存为 MP4 文件。
  - 写入本地输出目录。
- 输出：
  - 成功：用户可离线观看本地文件。
  - 失败：输出失败并反馈原因。
- 异常：
  - 磁盘空间不足
  - 输出路径不可写
  - 文件保存中断

## 模块关系与依赖
- 前置依赖：
  - 内容发现与站点访问 -> 视频检测与参数设置
  - 视频检测与参数设置 -> 录制执行
  - 录制执行 -> 输出保存
- 核心数据流：
  - 目标站点页面 -> 检测到视频流 -> 用户确认参数 -> 开始录制 -> 本地 MP4 输出
- 与现有系统耦合点：
  - 集成浏览器容器
  - 视频流检测逻辑
  - 本地磁盘写入
  - 站点兼容策略

## 当前架构风险
1. 站点兼容性天然不稳定，需要把能力差异显式化。
2. 高速录制并非所有站点可用，前台文案必须明确。
3. 录制场景比下载场景更依赖持续播放和环境稳定，异常反馈要更即时。
4. 官方 FAQ 目前只确认“输出分辨率”和“录制速度”两个可配置项，其他高级设置不能默认写成已上线能力。
5. 当前正式版本已确认不支持自动录制和队列录制，写 PRD 时不能把这两项写成现有能力。
