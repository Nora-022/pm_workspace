# 00 规划上下文（Planning Context）

## 产品定位
- 产品：RecordFab
- 产品类型：面向流媒体录制场景的桌面软件
- 当前已确认定位：用于录制流媒体视频、直播、在线课程，并将结果保存为本地 MP4 文件

## 当前最关键的策略边界
1. 录制边界
- 以“录制”而非“下载解析”为核心价值。
- 支持流媒体、社媒内容、在线课程、直播四类核心场景。
- 通过集成浏览器和自动检测视频流，减少传统屏幕录制的框选和误录问题。

2. 质量与效率边界
- 输出分辨率当前公开为 720p / 1080p。
- 录制速度支持 1x 到 5x，但部分站点可能仅支持 1x。
- 录制文件当前公开输出为 MP4。

3. 平台边界
- 官方公开系统要求当前以 Windows 为主。
- 录制时依赖联网环境。
- 录制过程中会限制用户在 RecordFab 内的其他操作，以保证稳定性。

4. 产品表达边界
- 对外强调“高质量录制”和“自动检测”，不应混淆成普通桌面录屏工具。
- 与下载型产品相比，核心叙事应是“无法直接下载时的稳定留存方案”。

## 当前知识状态
- 已确认：
  - 支持录制流媒体视频、直播、在线课程、社媒内容
  - 支持 720p / 1080p
  - 支持 1x, 1.5x, 2x, 3x, 4x, 5x 录制速度
  - 集成浏览器
  - 自动检测视频流
  - 官方产品页展示价格为 129.99 美元
  - Windows 11/10/8.1/8/7（32/64 bit）系统要求
  - 内部资料提到当前版本号为 `V1.0.0.0`
  - 内部资料显示首版核心模式为“手动录制”
  - 内部资料显示产品主界面至少包含 `Home` 和 `My Files` 两个 Tab
  - 内部资料显示输出格式支持 `MP4` 和 `MKV`
- 待确认：
  - 会员体系与 SKU 细分
  - 任务队列上限与并发模型
  - 官网 `5x` 与内部资料 `最高 2x / V1 为 1x->2x` 的版本口径差异
  - “自动检测视频流”与“手动录制模式”在当前版本中的具体关系
  - 队列录制当前是否已上线，还是仍属于规划能力

## 规划建议（后续优先补）
1. 先补业务规则与商业模型，避免后续 PRD 出现价格、试用、授权口径不一致。
2. 先补页面与任务流，因为 RecordFab 的录制体验高度依赖状态反馈。
3. 后续应把“站点差异”单独沉淀，尤其是 5x 速度是否可用、是否必须前台运行等差异。
