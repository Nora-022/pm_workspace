# 00 产品背景（Product Context）

## 1. 文件定位

本文件用于记录 `RecordFab` 的产品背景、产品线角色和长期判断边界。

它不承担以下职责：
- 不记录已经定版的产品事实
- 不替代 `01-07` 核心文件
- 不作为版本变更明细文档

当前版本的定版事实分别沉淀在 `01-07` 专题文件中。

## 2. 产品背景

### 2.1 产品角色
- `RecordFab` 是面向流媒体录制场景的客户端产品。
- 在产品线中，它承担“下载方案补足”的角色。
- 与下载型产品相比，它的核心价值不在于直接获取源文件，而在于当下载不可用或不稳定时，仍能帮助用户保存内容。

### 2.2 核心场景
- 直播流保存
- 流媒体内容保存
- 下载受限场景下的替代方案

### 2.3 产品线关系
- `RecordFab` 是 `StreamFab` 的补充产品。
- 产品线层面曾规划 `StreamFab -> RecordFab` 的失败兜底协同路径。
- 在知识库中，需要持续区分“已经上线的协同能力”和“规划过但尚未落地的协同方向”。

## 3. 长期边界

### 3.1 产品边界
- `RecordFab` 是录制产品，不是下载器。
- 自动检测视频流不等于直接下载源文件。
- 手动开始、手动结束、录制中遮罩、不能一键重试，都是录制产品的典型边界。

### 3.2 站点边界
- “支持 1000+ 网站”代表覆盖范围，不代表所有站点体验一致。
- 不同站点在速度上限、稳定性、直播支持和异常表现上可能存在显著差异。

### 3.3 版本边界
- 历史资料、官网描述和当前正式版本之间可能存在版本口径差异。
- 知识库维护时，应始终以当前正式版本事实为准。
- 历史版本变化应单独维护在 changelog 中，不直接混入当前版本定义。
