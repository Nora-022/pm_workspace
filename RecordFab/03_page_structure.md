# 03 页面结构与布局（Page Structure）

## 1. 核心架构设计
- 以“浏览-检测-参数设置-录制-结果管理”为主链路。
- 页面围绕单次录制任务闭环组织。
- 集成浏览器是核心工作区。

## 2. 页面清单
1. `Home`
2. 集成浏览器工作区
3. 录制控制区
4. 录制中状态页
5. `My Files`
6. 设置页
7. 授权 / 购买页

## 3. 已确认界面事实
- 用户在产品内登录流媒体服务账号并找到目标视频。
- `Start` 按钮位于右侧区域。
- 点击 `Start` 后设置输出分辨率、录制速度和输出格式。
- `Start` 在检测到可录制视频流后点亮。

## 4. Home
- 负责导航、检索和视频录制入口。
- 推荐内容：
  - 快速进入浏览器
  - 检索入口
  - 视频录制入口
  - 最近记录摘要

## 5. 集成浏览器工作区
- 页面组成：
  - 顶部地址区 / 返回前进
  - 站点内容展示区
  - 右侧录制控制区
- 控制区必要元素：
  - 检测状态
  - `Start`
  - 站点能力提示
- 点击 `Start` 后进入录制前配置弹窗
- 配置弹窗字段：
  - 输出分辨率
  - 录制速度
  - 自定义录制时间

## 6. 录制中状态页
- 主要展示：
  - 已录制时长
  - 当前速度
  - `Stop`
- 录制时视频播放区域存在遮罩，用户无法直接操作视频。

## 7. My Files
- 当前定位偏文件管理。
- 承载历史记录和文件列表。
- 当前不承载独立的进行中任务列表。
- 新增文件以视频卡片形式展示。
- 卡片展示：
  - 时长
  - 文件大小
  - 输出分辨率
  - 打开文件夹 icon
- 点击打开文件夹 icon 会打开本地目录。

## 8. 设置页
- 当前已确认的必要设置：
  - 输出分辨率
  - 录制速度
  - 输出格式
- 当前还存在通用设置项，例如输出目录。

## 9. 页面跳转关系
- `Home` -> 集成浏览器工作区
- 集成浏览器工作区 -> 录制中状态
- 录制完成后默认不自动跳转到 `My Files`
- 任意页 -> 设置页 / 授权页
