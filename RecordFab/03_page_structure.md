# 03 页面结构与布局（Page Structure）

## 1. 核心架构设计
- 以“浏览-检测-参数设置-录制-结果查看”为主链路。
- 页面围绕单次录制任务闭环组织，而不是围绕复杂管理后台。
- 集成浏览器是核心工作区，不应被弱化成附属窗口。

## 2. 页面清单
1. `Home`
2. 集成浏览器工作区
3. 录制控制区
4. 录制中状态页
5. `My Files`
6. 设置页
7. 授权 / 购买页

## 3. 基于官方产品页可确认的界面事实
- 安装并启动后，用户会先看到主界面。
- 用户需要在产品内登录流媒体服务账号并找到目标视频。
- `Start` 按钮位于右侧区域。
- 点击 `Start` 后设置输出分辨率和录制速度。

## 4. 基于内部资料可确认的页面事实
- 主界面至少包含两个 Tab：
  - `Home`
  - `My Files`
- `Home` 负责导航、检索和视频录制。
- `My Files` 负责文件存储、历史记录和结果管理。

## 5. Home
- 推荐内容：
  - 快速进入浏览器
  - 检索入口
  - 视频录制入口
  - 最近记录摘要
- 目标：
  - 降低首次启动理解成本
  - 让用户清楚这是流媒体录制工具

## 6. 集成浏览器工作区
- 页面组成：
  - 顶部地址区 / 返回前进
  - 站点内容展示区
  - 右侧录制控制区
- 控制区必要元素：
  - 检测状态
  - 输出分辨率选择
  - 录制速度选择
  - 输出格式
  - `Start` 主按钮
  - 站点能力提示

## 7. 录制中状态页
- 页面目标：
  - 清晰反馈录制已开始且进行中
  - 避免用户误以为应用卡死
- 建议内容：
  - 已录制时长
  - 当前速度
  - `Stop` 按钮
- 说明文案：
  - 录制期间会限制部分其他操作，以保证稳定性
  - 录制时视频播放区域存在遮罩，用户无法直接操作视频

## 8. My Files
- 目标：
  - 承接录制完成后的文件查看和管理
  - 承载历史记录和文件列表
  - 当前定位偏文件管理
- 推荐内容：
  - 历史记录
  - 文件列表
  - 打开目录
  - 结果摘要
- 边界：
  - 当前正式版本不承载独立的进行中任务列表

## 9. 设置页
- 当前已确认的必要设置：
  - 输出分辨率
  - 录制速度
  - 输出格式
- 当前还存在通用设置项，例如输出目录。
- 可作为待确认项保留占位：
  - 默认浏览器行为
  - 历史记录保留

## 10. 页面跳转关系
- `Home` -> 集成浏览器工作区
- 集成浏览器工作区 -> 录制中状态页
- 录制中状态页 -> `My Files`
- 任意页 -> 设置页 / 授权页
