# RecordFab Open Questions

## P0：现在最该补的
1. RecordFab 的正式产品定位文案是什么？
2. 当前支持的平台只有 Windows，还是还有其他版本？
3. 免费试用规则是什么？
4. 收费模式是什么？买断、订阅，还是混合？
5. 登录是否必须？未登录能否录制？
6. 当前是否支持任务列表、历史列表、失败重试？

## P1：需求写作会卡住的问题
1. 录制开始前是否必须完成视频流检测？
2. 当前录制速度选项是否全局一致，还是按站点动态变化？
3. 录制中是否允许用户继续浏览其他页面？
4. 停止录制后是否保留部分文件？
5. 录制完成后有哪些标准动作：
- 打开文件
- 打开目录
- 再录一个
- 分享

## P2：设计阶段会卡住的问题
1. 首页是否存在，还是直接进入集成浏览器？
2. 录制参数区的位置固定在哪里？
3. 录制中的状态反馈有哪些核心字段？
4. 当前产品有没有“最近录制”或“录制历史”模块？
5. 是否有站点能力提示组件？

## P3：技术与平台差异
1. 是否支持后台录制？
2. 是否支持多任务并发？
3. 是否支持计划录制？
4. 不同站点的限制如何表达？
5. 输出目录、文件命名、空间检查规则是什么？

## 建议记录方式
- 每确认一个问题，就同步更新：
  - `01_product_brief.md` 或对应专题文件
  - 对应的 `01-07` 核心文件
