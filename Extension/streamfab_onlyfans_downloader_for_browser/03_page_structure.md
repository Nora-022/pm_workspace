# 03 页面结构与布局（Page Structure）

## 页面清单（预设）
1. 插件主页（Popup / Sidebar）
2. 用户授权信息模块（顶部固定区）
3. Detected（Onlyfans 检测结果页）
4. Downloads（下载管理页）
5. Dashboard（License Info / Settings）
6. CoApp 引导页
7. 剧集/分组选择弹窗（如适用，待确认）

## 顶部用户授权信息模块（预设）
- 试用：邮箱 + 剩余下载次数 + Trial + Buy Now + Dashboard icon
- 订阅：邮箱 + 当日下载次数 + 订阅方案 + Dashboard icon

## Detected（预设）
- 前置引导：非 Onlyfans / 未登录 / 未播放
- 无跨 Origin，列表上限 50
- Downloading 存在时暂停新检测
