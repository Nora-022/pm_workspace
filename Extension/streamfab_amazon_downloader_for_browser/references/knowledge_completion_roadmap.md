# Amazon Knowledge Completion Roadmap

## Stage 1: Logged-in Reality Check
- capture one movie detail page
- capture one episodic detail page
- capture one playback page
- capture one rental / purchase title if available
- record actual CTA text and entitlement states

## Stage 2: Extension Behavior Check
- verify detection entry point
- verify dialog tree structure
- verify actual settings exposed in the extension
- verify unsupported-state wording for non-VOD content

## Stage 3: Business Rule Lock
- confirm trial rules
- confirm premium daily quota
- confirm rental / purchase support boundary
- confirm channels / sports / live policy

## Stage 4: Archive Maturity
- rewrite unstable notes into stable conclusions
- move repeated findings into the most compact reference files
- reduce duplicated statements across `00-07`, `context`, and `references`
- keep only the notes that remain genuinely useful for future recall
