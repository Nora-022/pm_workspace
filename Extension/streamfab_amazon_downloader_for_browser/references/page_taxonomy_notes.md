# Amazon Page Taxonomy Notes

## Purpose
- Personal archive of which Prime Video page types matter most for later recall.

## 1. Browse Pages
- Examples:
  - homepage rails
  - category pages
  - search-like listing pages
- Memory value:
  - good for remembering taxonomy
  - weak evidence for real downloadable state

## 2. Movie Detail Pages
- Typical clues:
  - `Watch with Prime`
  - `Rent`
  - `Buy`
  - `More purchase options`
  - `Audio languages`
  - `Subtitles`
- Memory value:
  - best public source for entitlement wording and metadata richness

## 3. Episodic Detail Pages
- Typical clues:
  - season switcher
  - episode list
  - per-episode CTA
- Memory value:
  - best public source for hierarchy and batch-download relevance

## 4. Playback Pages
- Current state:
  - still not archived with real runtime evidence
- Memory value:
  - likely the most important missing page type for later verification

## 5. Sports / Live Pages
- Typical role in archive:
  - reminder that Prime Video contains non-standard VOD scenarios
- Current state:
  - should remain marked as unverified / probably unsupported until real behavior is seen
