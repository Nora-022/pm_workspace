# Amazon Entitlement Notes

## Purpose
- Personal archive of entitlement concepts visible around Prime Video pages.

## Entitlement Types Worth Remembering
- `Prime-included`
- `Join Prime`
- `Watch for free`
- `Rent`
- `Buy`
- channel-specific access
- region / availability restriction

## Why This Matters
- Amazon complexity is not mainly about site count.
- It is about multiple entitlement states coexisting within the same Prime Video site.

## Current Archive Rule
- When reading later notes, separate:
  - content type
  - entitlement type
  - page type
- These three axes should not be mixed together.
