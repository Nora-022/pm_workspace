# Amazon Design Principles Context

## Design Priorities
1. Single-site clarity
- The product should read as a Prime Video plugin, not as a general Amazon media tool.

2. Entitlement transparency
- UI should make Prime-included, rental / purchase, and unsupported states legible before task creation when possible.

3. Hierarchy preservation
- If Amazon pages expose `season -> episode`, the dialog should preserve that hierarchy rather than flattening it.

4. Marketing discipline
- Use only product-page-backed claims in banner and store materials.
- Avoid implying 4K, HDR, or full live/sports coverage.

5. Screenshot selection
- Prefer title-detail and episodic-detail screenshots over homepage-only screenshots.
