# Amazon Product Brief Context

## One-line Positioning
- StreamFab Amazon Downloader for Browser is a single-site Prime Video downloader plugin, not a multi-site generic downloader.

## Read This Before Writing
1. Target site stays `Prime Video` as one supported site.
2. Inside this site, different content and entitlement types must be distinguished:
   - Prime-included
   - rent / buy
   - channels
   - sports / live
3. Product-page-backed capabilities can be treated as confirmed marketing inputs:
   - up to `1080p`
   - `EAC3 5.1 / AAC 2.0`
   - `MP4 / MKV`
   - `H.264 / H.265`
   - subtitle remux / SRT export
   - scheduled new-episode download
4. Logged-in playback behavior is still not confirmed, so player-level assumptions must stay marked as pending.
