# Amazon Compliance Notes

## Messaging Boundaries
- Public knowledge docs may reference product-page claims, but unsupported capabilities must stay labeled as pending.
- Rental / purchased movie support should not be turned into a final commitment until extension behavior is validated.

## Scope Boundaries
- Prime Video is the supported site.
- Sports / live / channels should be treated as scope-sensitive content types, not default-supported scenarios.

## Documentation Discipline
- Keep confirmed facts, conservative inferences, and open questions clearly separated.
- If a statement comes only from marketing copy and not from extension behavior, keep that distinction visible in PM docs.
