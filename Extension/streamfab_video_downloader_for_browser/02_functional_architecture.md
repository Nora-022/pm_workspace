# 02 功能架构详解（Functional Architecture）

## 功能模块总览
- 模块 1：视频分析
- 模块 2：视频下载
- 模块 3：账号试用与授权

## 模块规格（输入 / 处理 / 输出 / 异常）

### 模块：视频分析
- 输入：视频 URL。
- 处理：调用开源 `yt-dlp` 代码库解析 URL。
- 输出：
  - 成功：返回分析结果，并在界面展示视频卡片与下载配置。
  - 失败：
    - 当前界面无历史数据时：展示“未检测到视频”。
    - 当前界面有历史数据时：不新增数据（即代表本次检测失败）。
- 异常：
  - 站点不支持（DRM）：引导用户下载/试用 StreamFab 客户端。
  - 站点不支持（非 DRM 且 `yt-dlp` 不支持）：提示“未检测到视频，请确保视频播放或者刷新页面，部分网站可能不支持。”

### 模块：视频下载
- 输入：视频 URL、用户 token 等授权信息、用户下载配置。
- 处理：插件将任务信息传给本地 CoApp，CoApp 执行下载并回传处理进度。
- 输出：
  - 下载中：插件界面展示进度。
  - 下载完成：界面通知任务完成。
- 异常：
  - 未安装/已卸载 CoApp。
  - 用户可下载任务数量小于发起任务数量：按任务排序过滤，仅放行可下载数量，其余任务拦截。
  - 试用用户可下载任务数 = 0：允许继续分析；点击下载时触发全局弹窗，提示试用机会用完并引导订阅。
  - 订阅用户场景拆分：`订阅已过期` 与 `订阅有效但当日额度为 0`。`订阅有效但当日额度为 0` 时：允许继续分析；点击下载触发全局弹窗。文案："You've reached today's download limit (100). Downloads will be available again tomorrow." 按钮："Got it"（关闭弹窗）。

### 模块：账号试用与授权
- 输入：用户账号。
- 处理：在授权后台执行账号校验。
- 输出：授权结果、账号权益（试用次数、试用剩余天数、订阅账号剩余下载次数、订阅有效期）。
- 异常：
  - 网络错误（高频）：允许用户手动重试。
  - 授权上限（较高频）：引导去用户中心解除已绑定授权。
  - 其他授权失败：提示联系客户支持。

## 模块关系与依赖
- 前置依赖：账号试用与授权 -> 视频下载。
- 数据流向：
  - 视频分析：URL -> `yt-dlp` 解析 -> 结果回传插件界面。
  - 视频下载：插件参数 -> CoApp -> 进度/结果回传插件界面。
- 与现有系统耦合点：
  - 开源 `yt-dlp` 解析能力。
  - 本地 CoApp 服务可用性。
  - 授权后台可用性与账号权益接口。
