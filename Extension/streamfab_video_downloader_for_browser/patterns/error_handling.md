# patterns/error_handling.md

## 错误处理模式

### 模式 1：能力不支持
- 场景：站点不支持、DRM 受保护内容、Chrome 商店版 YouTube 限制
- 反馈位置：Detected 页内联状态或引导卡片
- 用户下一步：
  - DRM：引导到 StreamFab 桌面端
  - Chrome YouTube 限制：引导使用 Edge 或官网版
  - 一般站点不支持：提示刷新页面或确认站点是否受支持

### 模式 2：商业级阻断
- 场景：试用次数耗尽、订阅过期、当日下载额度用尽
- 反馈位置：全局阻断弹窗
- 设计原则：这类错误影响“是否允许继续创建任务”，因此允许打断
- 用户下一步：
  - 升级订阅
  - 续费
  - 等待次日额度恢复

### 模式 3：环境问题
- 场景：CoApp 未连接、磁盘空间不足
- 反馈位置：Downloads 任务卡片内
- 状态处理：任务进入 `Failed`
- 用户下一步：修复环境后点击 `Retry`

### 模式 4：授权硬限制
- 场景：设备授权超限、授权失败
- 反馈位置：下载前校验或任务失败状态
- 用户下一步：
  - 去 Member Center 解绑设备
  - 联系支持

## 统一规则

- 技术异常优先局部反馈，不使用全局弹窗
- 商业级阻断使用统一弹窗与明确动作按钮
- 错误文案需包含原因和下一步，不只显示错误码
- `Retry` 不重复扣减配额
