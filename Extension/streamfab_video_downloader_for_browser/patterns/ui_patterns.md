# patterns/ui_patterns.md

## 页面模式清单

### 模式 1：Detected 视频卡片
- 使用场景：展示当前页面检测到的可下载视频
- 关键元素：
  - Checkbox
  - 缩略图和平台图标
  - 标题、时长、规格信息
  - 下载配置区域
  - 单项 `Download`
- 设计重点：
  - 检测结果按时间倒序
  - 配置项与视频信息保持同卡片上下文

### 模式 2：Downloads 任务卡片
- 使用场景：展示下载任务状态与操作
- 关键元素：
  - 任务标题
  - 进度条
  - 速度/大小/状态
  - `Cancel` / `Retry` / `Open Folder`
- 设计重点：
  - 状态与操作同位
  - 错误信息在卡片内局部反馈

### 模式 3：顶部授权信息模块
- 使用场景：Detected 与 Downloads 顶部公共区域
- 试用用户展示：
  - 头像
  - 邮箱
  - 剩余试用次数
  - `Trial` 标识
  - `Buy Now/Upgrade`
- 订阅用户展示：
  - 头像
  - 邮箱
  - 订阅类型
  - Dashboard 入口

### 模式 4：商业级阻断弹窗
- 使用场景：试用耗尽、订阅过期、当日额度为 0
- 关键要求：
  - 阻断下载动作
  - 明确说明限制原因
  - 提供唯一清晰的下一步

### 模式 5：能力限制提示卡
- 使用场景：DRM 视频、Chrome 商店版 YouTube 限制、站点不支持
- 关键要求：
  - 优先解释“为什么不能下载”
  - 再给替代方案或引导渠道
