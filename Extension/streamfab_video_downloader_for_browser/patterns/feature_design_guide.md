# patterns/feature_design_guide.md

## ytdlp 插件功能设计准则

### 适用范围

- 新增多站点下载能力
- 调整检测页和下载页交互
- 增加渠道差异提示
- 优化授权、配额和引导流程

### 设计检查项

1. 是否明确区分 Detected 与 Downloads
- Detected 负责当前页面识别结果
- Downloads 负责全局任务生命周期

2. 是否处理跨 Origin
- ytdlp 插件存在跨 Origin 模型
- 新功能不能假设所有检测结果都属于同一页面上下文

3. 是否区分商业阻断与技术异常
- 商业阻断：下载前拦截
- 技术异常：任务创建后在卡片内反馈

4. 是否覆盖渠道差异
- 官网版、Chrome 商店版、Edge 商店版能力不同
- 新设计要明确展示差异，不要默认三端一致

5. 是否兼容批量和并发策略
- 允许批量发起
- 最大并发 5
- 超出并发进入 Pending

### 交付建议

- 先更新 `01-07` 主文档，再回填到 `patterns/*`
- 若功能涉及固定交互模式，补充到 `ui_patterns.md`
- 若功能涉及状态流，补充到 `user_flows.md`
- 若功能涉及错误与恢复动作，补充到 `error_handling.md`
