# channel_capability_notes.md

用途：记录 ytdlp 插件在不同发布渠道下的能力差异，供产品、运营、文档维护时引用。

## 渠道清单

1. 官网侧载版
2. Chrome 商店版
3. Edge 商店版

## 关键差异

### 官网侧载版
- 支持 YouTube 下载
- 更新方式为手动下载安装

### Chrome 商店版
- 不支持 YouTube 下载
- 更新方式为商店自动更新

### Edge 商店版
- 支持 YouTube 下载
- 更新方式为商店自动更新

## 维护提醒

- 任何功能文档都不能默认三端完全一致
- 渠道差异是 ytdlp 插件的重要产品上下文
