# 03 Page Structure

## Known Candidate Page Types
- Home / discovery pages
- Program detail pages
- Episode detail pages
- Playback pages
- Ranking or category aggregation pages

## What Needs Verification
- Stable URL patterns for playable content
- Whether playback happens inline or on dedicated watch pages
- Whether season / episode hierarchy is explicit in the DOM or API responses
- Whether ads, geo prompts, or login prompts alter the page structure materially
