# PM Context Hub

目标：为产品规划、需求澄清、方案评估提供稳定上下文，不面向研发实现细节。

## 使用方式（推荐顺序）
1. 先读 `search_index.md`（按场景快速定位）
2. 再读 `product_line_index.md`（产品线全局状态）
3. 再读对应插件 `00_planning_context.md`（当前策略与边界）
4. 需要追溯时读 `00_decision_log.md`（关键决策）
5. 查看需求背景时读 `requirements/index.md` 与 `requirements/raw/`
