# Product Knowledge Hub

根目录只放两类内容：
- 各插件知识库文件夹（按插件名 snake_case 命名）
- 全局索引文件

## 快速入口
- 检索索引：`./search_index.md`
- 插件进度总览：`./plugin_progress_overview.md`
- 插件目录索引：`./plugins_index.md`
- 产品线全局索引：`./product_line_index.md`
- PM 使用入口：`./pm_context_hub.md`
- 共性规则：`./common_plugin_rules.md`
