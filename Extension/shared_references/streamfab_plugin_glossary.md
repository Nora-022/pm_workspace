# StreamFab Plugin Glossary

## Purpose
This file defines shared PM terms used across the StreamFab plugin workspace.

## Terms
- Plugin: One independent browser plugin product, usually mapped to one supported service or service family.
- Product line: The full set of StreamFab browser plugin products managed in this workspace.
- Root indexes: Workspace-level index files such as README.md, plugins_index.md, and product_line_index.md.
- Shared template: A reusable output skeleton stored in common_templates/.
- Shared reference: A centralized background or rule file stored in shared_references/.
- Plugin-local reference: A plugin-specific background file stored in <plugin>/references/.
- Plugin-local conclusion: A confirmed plugin fact written into plugin 01-07 files or 00_* planning files.
- Preset template plugin: The existing plugin chosen as the initialization baseline for a new plugin.
- Working document: A copied or instantiated document used for the current plugin task.

## Usage Rule
If a term is reused across multiple plugins or PM tasks, define it here instead of redefining it in each plugin folder.
