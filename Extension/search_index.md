# Search Index (Scenario -> File)

用途：做插件整体规划时，按问题类型快速定位到正确文件。

## A. 看全局（产品线层）
- 插件进度与业务阶段：`plugin_progress_overview.md`
- 产品线状态/插件清单：`product_line_index.md`
- 插件目录与定位：`plugins_index.md`
- 共性规则（跨插件）：`common_plugin_rules.md`
- PM 使用入口：`pm_context_hub.md`

## B. 看某个插件（单插件层）
- 先读：`<plugin>/00_planning_context.md`
- 再读：`<plugin>/00_decision_log.md`
- 最新需求背景：`<plugin>/requirements/index.md`
- 外部研究：`<plugin>/references/client_product_page_notes.md`、`<plugin>/references/site_research_notes.md`

## C. 按问题类型检索
- 产品定位/边界：`01_product_brief.md`
- 功能架构：`02_functional_architecture.md`
- 页面与信息结构：`03_page_structure.md`
- 交互与状态流：`04_interaction_details.md`
- 设计原则：`05_design_principles.md`
- 商业规则/权益：`06_business_rules.md`
- 技术与渠道限制：`07_technical_constraints.md`

## D. 按规划任务检索
- 做版本规划：
  1) `product_line_index.md`
  2) `<plugin>/00_planning_context.md`
  3) `<plugin>/00_decision_log.md`
- 做需求评审：
  1) `<plugin>/requirements/index.md`
  2) `<plugin>/requirements/raw/*`
  3) `04_interaction_details.md` + `06_business_rules.md`
- 做新插件调研：
  1) `<plugin>/references/client_product_page_notes.md`
  2) `<plugin>/references/site_research_notes.md`
