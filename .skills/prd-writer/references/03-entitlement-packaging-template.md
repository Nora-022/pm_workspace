# Entitlement & Packaging Template (授权与套餐模板)

目标：写清楚“谁在什么条件下可用什么能力”，避免研发和运营理解不一致。

## 1. 套餐模型

| 版本 | 计费方式 | 权益范围 | 限制 |
|---|---|---|---|
| Free | 免费 | 基础能力 | 额度/质量/并发限制 |
| Trial | 限时试用 | 准完整能力 | 次数与周期限制 |
| Monthly | 月付 | 全量或高级能力 | 自动续费规则 |
| Annual | 年付 | 全量或高级能力 | 折扣与权益差异 |
| Lifetime | 一次性 | 指定能力集合 | 升级与维护边界 |

## 2. 授权规则

- 登录要求：必须登录 / 离线宽限
- 设备规则：同时在线设备上限
- 授权同步：本地缓存 TTL + 服务端校验频率
- 跨平台权益：Win 与 Mac 是否通用

## 3. 配额规则

- 维度：按账号 / 按产品 / 按站点 / 按天周月
- 重置：自然日 / 滚动窗口
- 达限行为：拒绝新任务 / 排队等待 / 降级处理

## 4. 触发点与提示

- 触发升级时机：点击高级功能、配额不足、导出高规格
- 升级弹窗最小信息：当前限制、可获得权益、价格、续费说明
- 防误导：不得暗示不存在的权益

## 5. 争议与边界

- 退款和试用边界是否在产品内透出
- 区域差异定价的处理
- 历史用户权益迁移策略
