# NFR & SLO Baseline (非功能默认基线)

目标：当用户未给指标时，提供可讨论的默认值，并标注“待确认”。

## 1. 性能基线（建议默认）

- 关键交互响应：P95 < 500ms（待确认）
- 首次可操作时间：< 3s（待确认）
- 任务列表刷新：< 1s（待确认）

## 2. 稳定性基线

- 关键接口可用性：>= 99.9%（待确认）
- 可恢复失败比例：>= 95%（待确认）
- 崩溃率（桌面端会话）：< 0.3%（待确认）

## 3. 资源使用基线（桌面）

- 空闲 CPU 占用上限（建议）
- 任务运行内存上限（建议）
- 磁盘预留阈值（建议）

## 4. 安全与合规基线

- 登录态接口必须鉴权（待确认）
- 敏感字段默认脱敏落日志（待确认）
- 合规提示在关键入口可见（待确认）

## 5. 可观测性基线

- 任务全链路追踪 ID
- 关键失败码可聚合统计
- 用户可见错误与研发错误码可映射
