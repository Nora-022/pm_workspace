# Cross-Product Context Cards (跨产品语境卡)

目标：在同一 PRD 里快速定位产品边界，避免“把别的产品能力写进来”。

以下卡片用于“推演与约束”，不是强制事实库；遇到真实项目配置，以当前产品配置为准。

## DVDFab（光盘处理）

- 典型输入：光盘 / ISO / 文件夹
- 典型输出：拷贝、压缩、格式转换
- 高风险点：驱动兼容、读盘失败、区域码/受保护内容边界
- PRD 关注：光驱检测、任务容错、长任务稳定性

## StreamFab（流媒体下载）

- 典型输入：流媒体站点内容链接与账号态
- 典型输出：本地视频文件（含音轨/字幕策略）
- 高风险点：站点策略变更、配额、解析失败
- PRD 关注：解析状态、配额反馈、队列恢复、失败重试

## UniFab（AI 音视频增强）

- 典型输入：本地视频文件
- 典型输出：增强后视频/音频
- 高风险点：GPU/显存不足、模型耗时、参数复杂性
- PRD 关注：参数预设、资源预检、可取消与进度反馈

## MusicFab（音乐下载与转换）

- 典型输入：音乐平台链接/歌单
- 典型输出：音频文件与元数据
- 高风险点：元数据一致性、批量任务失败处理
- PRD 关注：ID3/封面、批量队列、格式策略

## RecordFab（录制）

- 典型输入：播放源与录制参数
- 典型输出：录制文件
- 高风险点：录制中断、源受限、同步偏差
- PRD 关注：录制状态、中断恢复、质量与速度平衡

## PlayerFab（播放）

- 典型输入：本地媒体库/光盘/部分在线源
- 典型输出：播放体验与媒体管理
- 高风险点：解码兼容、字幕和音轨匹配、媒体库索引
- PRD 关注：播放状态、解码降级、媒体库一致性

## BookFab（文本/电子书）

- 典型输入：文本或书籍内容源
- 典型输出：可阅读内容与管理能力
- 高风险点：版权与格式兼容
- PRD 关注：内容导入、章节结构、阅读状态同步（若有）

## 如何使用这些卡片

- 新需求先定位主产品，再列出可能影响的相邻产品。
- 若跨产品复用能力，必须写清“复用边界”和“不复用项”。
- 一旦与当前产品真实规则冲突，优先使用项目内知识库与最新业务规则。
