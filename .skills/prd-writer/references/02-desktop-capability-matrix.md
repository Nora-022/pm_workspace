# Desktop Capability Matrix (桌面端能力矩阵)

目标：覆盖桌面客户端 PRD 常漏项，避免只写 Web 思维。

## A. 平台与安装

- 平台：Windows / macOS
- 安装方式：完整安装 / 增量升级 / 静默升级
- 卸载策略：是否保留用户配置与下载历史
- 最低系统要求：CPU / RAM / 磁盘 / GPU

## B. 任务引擎

- 队列模式：串行 / 并行（并发上限）
- 任务状态：Pending / Running / Paused / Failed / Done
- 断点续传：支持范围、恢复策略
- 失败重试：次数、间隔、终止条件

## C. 媒体管线

- 输入源：URL / 本地文件 / 光盘 / 设备录制
- 输出容器：MP4 / MKV / MP3 / FLAC 等
- 编解码：软编 / 硬编（Intel QSV / NVIDIA / AMD）
- 字幕与音轨：保留、转换、分离规则

## D. 本地资源约束

- 磁盘空间预估与校验
- 文件命名冲突处理
- 路径非法字符处理
- 长路径与权限失败处理

## E. 可观测性

- 用户可见：进度、速度、剩余时间、错误提示
- 研发可见：日志、错误码、任务追踪 ID

## F. PRD 写法建议

- 至少明确 3 类失败：网络失败、资源不足、权限失败。
- 至少明确 2 类恢复：自动恢复、用户触发恢复。
- 明确哪些场景强依赖联网，哪些允许离线继续。
