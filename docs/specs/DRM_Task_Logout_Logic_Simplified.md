# 产品逻辑规范：账号登出对下载任务的影响

**场景定义：** 用户在 StreamFab 内置浏览器中退出了流媒体网站（如 Netflix）账号。

---

## 1. 待下载 (Queueing)
*   **策略：** **禁止启动**
*   **交互：** 隐藏任务列表，显示“请登录”占位图。
*   **原因：** 任务启动需申请 DRM 密钥 (License)，账号退出导致鉴权失效，无法获取密钥。

## 2. 下载中 (Downloading)
*   **策略：** **允许继续**
*   **交互：** 任务正常进行，增加状态警示。
*   **原因：** 密钥已在下载启动时获取并缓存，后续分片下载仅依赖 CDN，通常不受登录态影响。

## 3. 下载失败 (Failed)
*   **策略：** **禁止重试**
*   **交互：** 点击重试时提示需重新登录。
*   **原因：** 重试视为新任务，需重新发起密钥申请流程，无登录态无法完成。

## 4. 已暂停 (Paused)
*   **策略：** **禁止恢复**
*   **交互：** 恢复操作触发登录提示。
*   **原因：** 暂停期间会话可能过期，恢复任务需重新鉴权。
