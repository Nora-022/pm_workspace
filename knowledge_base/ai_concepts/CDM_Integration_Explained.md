# 揭秘下载器的核心：内置 CDM (The Ghost in the Shell)

你问到了这个行业里**最敏感、最核心**的技术点。StreamFab 之所以能下载 Netflix，全靠这个“内置 CDM”。

## 1. 什么是 CDM (Content Decryption Module)?
在正规的浏览器（如 Chrome）里，CDM 是一个**黑盒组件**（通常是一个 `.dll` 或 `.so` 库）。
*   **职责:** 它是 Widevine DRM 的**守门人**。它负责保管私钥、生成挑战书 (Challenge)、解密 License，甚至直接解密视频帧。
*   **特点:** 它是一个**不透明**的保险箱。JS 代码只能把加密数据塞进去，然后等它吐出解密后的画面。**普通的浏览器 JS 拿不到里面的 Key。**

## 2. 为什么下载器要“内置”它？
如果下载器只是简单地调用 Chrome 浏览器的 CDM，它只能在屏幕上播放视频（因为 CDM 解密完直接送给显卡渲染了），**下载器拿不到中间的 MP4 文件**。

为了能把视频**保存下来**，下载器必须**自己扮演浏览器**。

### 怎么做到“自己扮演”？
StreamFab 的开发团队做了一件很硬核的事情：
1.  **提取 (Extraction):** 他们从真实的设备（比如一台 Android 手机或旧版 Chrome）中，把那个 CDM 模块（及其私钥证书 Client ID）**提取**了出来。
2.  **集成 (Integration):** 他们把这个提取出来的 CDM 模块（或者逆向工程后的算法）**直接嵌入到了下载器的代码里**。

## 3. “模拟成合法设备”是什么意思？
当 StreamFab 向 Netflix 申请 License 时，它必须证明自己是良民。
*   **Netflix 问:** "你是谁？"
*   **StreamFab (举起提取来的证书):** "我是 Chrome 浏览器 v120，运行在 Windows 上。"（实际上它是一个 Python/C++ 程序）
*   **Netflix 检查证书:** "嗯，签名是对的，是 Google 颁发的合法证书。通过！"

**这就是所谓的“模拟”：** 下载器盗用了合法设备的身份证明（Client Certificate），让 Netflix 误以为它是一个正规的浏览器，从而骗取解密钥匙。

## 4. 风险与猫鼠游戏
*   **L3 CDM:** 大多数下载器使用的是 Widevine L3 级别的 CDM（软件解密）。这种 CDM 容易被提取，但也容易被 Google 封杀（Revoke）。一旦某个证书被封，StreamFab 就会发布更新，换一个新的证书。
*   **L1 CDM:** 涉及硬件安全区 (TEE)，极难提取，通常只能录屏，不能无损下载。

**总结：**
“内置 CDM”就是下载器**私藏的一把万能钥匙**。有了它，下载器就不再需要求助浏览器，而是可以直接跟 Netflix 的服务器对话，把 Content Key 骗到手，然后在内存里自己解密视频。
