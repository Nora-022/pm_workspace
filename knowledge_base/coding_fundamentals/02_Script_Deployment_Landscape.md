# 脚本栖息地：代码应该在哪里运行？(Deployment Landscape)

> **Owner:** Alex Chen
> **Status:** Draft
> **Last Updated:** 2026-02-11

你问到了一个非常本质的问题：**代码写好了，它住在哪里？**
这取决于你的脚本是“宠物”还是“军队”。

## 1. 本地战场 (Local Environment)
*场景：个人工具、一次性任务、开发辅助。*

| 栖息地 | 描述 | 典型案例 | 优缺点 |
| :--- | :--- | :--- | :--- |
| **Terminal / IDE** | **手动触发**。写完代码，点一下运行。 | 批量改文件名、爬取一次数据。 | ✅ 最简单<br>❌ 人不在就停了 |
| **OS Scheduler** | **定时触发**。Windows 计划任务 / Linux Crontab。 | **你刚才做的日报机器人**、定时清理垃圾文件。 | ✅ 免费、稳定<br>❌ 电脑必须开机 |
| **Git Hooks** | **动作触发**。当你 `git commit` 时自动运行。 | **"工程里加个脚本"** (见下文详解)。 | ✅ 强迫执行规范<br>❌ 配置稍显复杂 |

### 🔍 深度解析："在工程里加一个脚本"
当你听到同事说这句话时，通常指以下两种情况：

#### A. 快捷指令 (NPM Scripts / Makefile)
在一个大工程里，启动命令可能很长。我们写一个“别名脚本”。
*   **文件位置:** `package.json` (前端) 或 `Makefile` (后端)
*   **代码:** `"start": "node ./src/server/index.js --env=prod"`
*   **用法:** 以后只需敲 `npm start`，不需要记那串长命令。

#### B. 门神脚本 (Pre-commit Hooks)
为了防止烂代码提交上去，我们在工程的 `.git/hooks` 目录里放一个脚本。
*   **逻辑:** "在你提交代码前，自动跑一遍检查。如果有错，直接报错，禁止提交。"
*   **场景:** 自动格式化代码、检查是否有密码泄露。

## 2. 云端战场 (Cloud & Server)
*场景：24小时待命、服务大众、团队协作。*

| 栖息地 | 描述 | 典型案例 | 优缺点 |
| :--- | :--- | :--- | :--- |
| **VPS (云服务器)** | **一台永远不关机的电脑**。买个阿里云/AWS，SSH 连上去跑脚本。 | 个人博客、复杂的爬虫、Telegram 机器人。 | ✅ 掌控一切<br>❌ 要花钱，要自己维护系统 |
| **Serverless (云函数)** | **按次付费的杀手**。不需要服务器，上传代码，有人访问才运行。 | **飞书机器人(进阶版)**、微信小程序后台。 | ✅ 极便宜、免运维<br>❌ 有冷启动延迟 |
| **CI/CD Pipeline** | **流水线**。代码提交到 GitHub 后，云端自动分配一台机器跑脚本。 | **自动化测试**、自动打包发布 APP。 | ✅ 团队协作标配<br>❌ 依赖平台 (GitHub Actions) |

### 🔍 深度解析：GitHub Actions (CI/CD)
这是目前最流行的“脚本自动运行”方式。
你不需要买服务器。只要你在项目里写一个 `.yaml` 配置文件，GitHub 就会免费给你提供一台虚拟电脑。
*   **流程:** 你提交代码 -> GitHub 启动虚拟机 -> 拉取代码 -> **运行你的脚本** -> 虚拟机销毁。
*   **妙用:** 很多人用这个来**白嫖算力**做定时任务（比如每天早上自动签到）。

## 3. 客户端/边缘 (Client Side)
*场景：寄生在别人的软件里。*

| 栖息地 | 描述 | 典型案例 |
| :--- | :--- | :--- |
| **Browser Extension** | **油猴脚本 (Tampermonkey)**。寄生在浏览器里，修改网页。 | 屏蔽广告、解除视频倍速限制、自动填表。 |
| **Excel VBA / Office** | **宏**。寄生在 Office 文档里。 | 财务自动报表、Word 自动排版。 |
| **Shortcuts** | **快捷指令**。寄生在手机操作系统里。 | iOS 自动打开付款码、到家自动发短信。 |

---

## 🏆 总结：如何选择？

1.  **如果不关电脑也能跑：** 选 **Windows 计划任务** (最快上手)。
2.  **如果不想开电脑，且脚本很小：** 选 **Serverless (云函数)** 或 **GitHub Actions**。
3.  **如果是团队项目，为了大家方便：** 加到 **npm scripts** 或 **Makefile** 里。
4.  **如果是为了修改别人的网页：** 写 **油猴脚本**。
