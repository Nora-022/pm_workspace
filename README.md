# Product Management Workspace

欢迎来到你的数字化作战指挥部。这是一个结构化的 PM 工作空间，旨在利用 Git 进行版本控制和知识管理。

## 📂 目录结构说明

### `docs/` - 文档中心
存放所有的产品需求文档 (PRD) 和规格说明书。
- **`drafts/`**: 草稿箱。正在撰写、未定稿的想法和文档。
- **`arch/`**: 归档区。已经过时或被废弃的历史文档（不要删除，移到这里）。

### `meeting_notes/` - 会议纪要
记录需求评审、每日站会、头脑风暴等会议的决议和待办项。
建议命名格式：`YYYY-MM-DD_会议主题.md`

### `plans/` - 规划与排期
- Roadmap (路线图)
- Gantt Charts (甘特图)
- Release Plans (发布计划)

### `.ai_agents/` - AI 军火库
存放你的自定义 AI Agent 提示词和配置文件。
- 这里的每一个 `.md` 文件都是一个独立的智能体。
- 使用 Git 管理它们，意味着你可以随时回滚到“那个虽然笨但听话”的版本。

## 🚀 快速开始
1. **新建文档**: 在对应目录下创建 Markdown 文件。
2. **保存进度**: 在终端执行 `git add .` 然后 `git commit -m "你的备注"`。
3. **调用 Agent**: 使用 `@` 符号在 Trae 中调用 `.ai_agents` 里的专家辅助你工作。
