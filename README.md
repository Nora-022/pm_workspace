# PM Workspace Knowledge Base

This repository is a long-term product knowledge backup for my work. It stores structured documentation, references, and working context for the products I manage, and it will continue to be expanded over time.

The main purpose of this repository is to preserve important product context, support future follow-up work, and reduce context loss during handoff or later product iteration.

## Repository Structure

### `Extension/`
This folder contains the product knowledge base for browser extension products.

It includes:
- common templates and shared references
- product line indexes and search indexes
- plugin-specific knowledge folders for individual extension products
- structured files for product briefs, architecture, interaction details, business rules, constraints, requirements, and supporting references

### `RecordFab/`
This folder contains the product knowledge base for the RecordFab client product.

It includes:
- product planning and decision records
- product brief and functional architecture documents
- page structure and interaction design details
- business rules and technical constraints
- requirements, reusable patterns, references, and contextual notes for future work

## Maintenance

This repository is a living knowledge archive. New product documents, research notes, requirements, and reference materials will be added continuously as the products evolve.
